# Velora 文内查找

文内查找复用左侧搜索区域，不在编辑区常驻工具栏。`Cmd/Ctrl+F` 打开当前文档查找并选中原查询；侧栏搜索图标仍搜索整个工作区的文件名与文件内容。

- 查询使用 macOS/Windows 文本输入通道，支持中文组合输入、粘贴与退格；组合输入确认后才发起搜索。
- 当前文档查找读取内存中的活动标签，包括未保存编辑；编辑内容或切换标签后会重新查找。
- 结果显示文件名、行号和片段。点击结果或在搜索框按 Enter 跳转；Shift+Enter、`Cmd/Ctrl+G`、`F3` 及其反向快捷键可切换匹配。
- 匹配本身交给 ripgrep 的库（`grep-searcher` + `grep-regex`，进程内调用），行切分与偏移记账都由引擎负责；文内查找与工作区搜索共用同一份编译结果。
- 大小写不敏感按 Unicode 折叠，中文、带音标拉丁字母与 `İ`/`ı` 这类非 ASCII 也参与折叠；模糊模式仍是子序列匹配。
- 正则模式支持跨行：`\n`、`[\s\S]`、`(?s)` 都能跨过行界；`.` 依 ripgrep 默认仍不跨行。
- 正则写错时面板直接显示引擎给出的诊断并停止搜索，不再把坏模式当成普通词静默搜下去。
- 结果列表、正文高亮、`F3`/`F4` 落点与「全部替换」读同一张命中表（按缓冲区版本 + 查询 + 开关缓存，跳转只取表上索引，不再重扫整篇）。命中跨过两个内容块时：高亮按块切段、源码模式给出真正的跨块选区、全部替换按字节写回真替换。
- 侧栏只列出前 200 项，前后查找快捷键仍可继续导航整篇文档中的后续匹配。
- 在所见即所得视图中，正文文字可被选中；若匹配的是隐藏的 Markdown 标记，编辑器会定位到邻近光标位置。

这一功能已有未保存内容、中文与英文匹配、快捷键、标签切换和搜索框组合输入的自动化用例，另有引擎层快照、跨行/跨块链路与 10 MiB 文档的性能闸门。原生窗口视觉检查仍需可操作桌面截图。
