# Velora 文内查找

文内查找复用左侧搜索区域，不在编辑区常驻工具栏。`Cmd/Ctrl+F` 打开当前文档查找并选中原查询；侧栏搜索图标仍搜索整个工作区的文件名与文件内容。

- 查询使用 macOS/Windows 文本输入通道，支持中文组合输入、粘贴与退格；组合输入确认后才发起搜索。
- 当前文档查找读取内存中的活动标签，包括未保存编辑；编辑内容或切换标签后会重新查找。
- 结果显示文件名、行号和片段。点击结果或在搜索框按 Enter 跳转；Shift+Enter、`Cmd/Ctrl+G`、`F3` 及其反向快捷键可切换匹配。
- ASCII 查询不区分大小写；中文等非 ASCII 查询按原文精确匹配。侧栏只列出前 200 项，前后查找快捷键仍可继续导航整篇文档中的后续匹配。
- 在所见即所得视图中，正文文字可被选中；若匹配的是隐藏的 Markdown 标记，编辑器会定位到邻近光标位置。

这一功能已有未保存内容、中文与英文匹配、快捷键、标签切换和搜索框组合输入的自动化用例。原生窗口视觉检查仍需可操作桌面截图。
