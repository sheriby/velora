# Velora 主题与长文排版

这份文档供界面审核。内置主题使用 Velora 自己的 GPUI 配色与排版参数，没有复制第三方主题代码或图片。

## 参考与取舍

- [Typora 主题库](https://theme.typora.io/)展示了纸页、深色和低干扰等多种写作方向；Velora 采用整套窗口与文档统一配色，而非只更换编辑区背景。
- [Typora 的排版说明](https://support.typora.io/Typeset/)把书写区域宽度、段落间距、引用、代码和图片都视为阅读体验的一部分。Velora 会用主题参数控制这些层级。
- [Typora 的专注模式与打字机模式](https://support.typora.io/Focus-and-Typewriter-Mode/)值得借鉴：当前行强调与让光标停在舒适位置应是可选行为，不能改变 Markdown 文件本身。
- [Obsidian 外观说明](https://obsidian.md/help/appearance)将系统跟随、浅色/深色和自选主题分开；Velora 保留系统跟随，并提供多套固定风格。

## 内置风格

| 主题 | 方向 | 主色 | 正文背景 | 排版节奏 |
|---|---|---|---|---|
| Velora Light | 清晰中性 | 紫色 | 纯白 | 标准长文 |
| Velora Dark | 克制深色 | 浅紫 | 深灰 | 标准长文 |
| Paper | 暖纸页 | 陶土色 | 暖白 | 宽松行距、轻标题 |
| Forest | 清爽自然 | 深绿 | 淡米绿 | 稍紧凑、适合笔记 |
| Midnight | 夜间技术写作 | 雾蓝 | 深蓝灰 | 柔和对比 |
| Ink | 暖墨夜读 | 柔珊瑚 | 暖深黑 | 宽松行距、轻标题 |

正文、次要文字、强调色和代码文本与各自背景的设计对比度均不低于 4.5:1。主题切换只影响外观，不应改变文档内容。用户在设置中明确选择的字体优先于主题建议。

## 后续排版验收

需要用同一组中文、英文和混排长文，逐项检查标题六级层次、段落间距、列表、引用、任务、表格、图片、代码块、行内代码、链接与窄窗口重排。专注模式、打字机模式和写作列宽控制将在主题基础稳定后加入，再用原生窗口审核。
