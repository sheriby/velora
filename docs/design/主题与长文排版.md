# Velora 主题与长文排版

这份文档供界面审核。内置主题使用 Velora 自己的 GPUI 配色与排版参数，没有复制第三方主题代码或图片。

## 参考与取舍

- [Typora 主题库](https://theme.typora.io/)展示了纸页、深色和低干扰等多种写作方向；Velora 采用整套窗口与文档统一配色，而非只更换编辑区背景。
- [Typora 的排版说明](https://support.typora.io/Typeset/)把书写区域宽度、段落间距、引用、代码和图片都视为阅读体验的一部分。Velora 会用主题参数控制这些层级。
- [Typora 的专注模式与打字机模式](https://support.typora.io/Focus-and-Typewriter-Mode/)值得借鉴：当前行强调与让光标停在舒适位置应是可选行为，不能改变 Markdown 文件本身。
- [Obsidian 外观说明](https://obsidian.md/help/appearance)将系统跟随、浅色/深色和自选主题分开；Velora 保留系统跟随，并提供多套固定风格。

## 内置风格

| 主题 | 方向 | 主色 | 正文背景 | 排版节奏 |
|---|---|---|---|---|
| Velora Light | 清晰中性 | 紫色 | 纯白 | 标准长文 |
| Velora Dark | 克制深色 | 浅紫 | 深灰 | 标准长文 |
| Paper | 暖纸页 | 陶土色 | 暖白 | 宽松行距、轻标题 |
| Forest | 清爽自然 | 深绿 | 淡米绿 | 稍紧凑、适合笔记 |
| Midnight | 夜间技术写作 | 雾蓝 | 深蓝灰 | 柔和对比 |
| Ink | 暖墨夜读 | 柔珊瑚 | 暖深黑 | 宽松行距、轻标题 |

正文、次要文字、强调色和代码文本与各自背景的设计对比度均不低于 4.5:1。主题切换只影响外观，不应改变文档内容。Paper 和 Ink 在 macOS 使用宋体，在其他平台使用 Georgia；其余主题使用系统字体。正文默认跟随主题，用户在设置中明确选择的正文和代码字体优先于主题建议。旧版主题文件缺少字体字段时继续使用系统字体。

Markdown 阅读列的最大宽度由主题决定：Paper 为 700 像素，Ink 为 720 像素，其余内置主题为 760 像素。窄窗口下列宽随可用空间缩小；代码文件仍使用较宽的浏览区域。旧版主题文件缺少宽度字段时按 760 像素处理。

所见即所得视图使用分层间距：标题前留白随标题级别增加，标题后紧接正文时缩小间距，连续列表项的间距减半；引用组内部继续紧密排列。源码视图保留均匀行距。这些间距从主题的基础块间距计算，所以不同主题仍保持各自节奏。

设置中的主题列表用小幅色卡显示每款主题的正文底色、文字色和强调色；导入的自定义主题也按实际颜色显示，无需先应用就能辨认风格。

“视图”菜单提供专注模式：开启后淡化当前编辑行以外的文档行，表格和分组块按整组处理；光标离开文档、跨块选区或切换到源码与代码文件时恢复正常显示。这个开关只影响当前窗口，不写入 Markdown。

同一菜单提供打字机模式：所见即所得编辑时给文档顶部留出半屏空间，并在输入或移动光标后将光标保持在视口中部附近；手动滚动仍可浏览其他位置，继续输入后再回到光标。源码与代码标签页使用普通滚动。它同样只影响当前窗口。

## 后续排版验收

需要用同一组中文、英文和混排长文，逐项检查标题六级层次、段落间距、列表、引用、任务、表格、图片、代码块、行内代码、链接与窄窗口重排。用户可调的写作列宽将在主题基础稳定后加入，再用原生窗口审核。
