# Velora 界面原型说明

这份原型展示桌面编辑器的工作区布局和简洁的中性视觉方向，页面可以在浏览器中直接打开，并按系统颜色偏好选择浅色或深色。

左侧活动栏提供文件、搜索和大纲入口，侧边栏只呈现当前内容；中央区域展示紧凑的文档标签、编辑内容及状态栏。代码文件使用同一窗口内的标签编辑，支持语法高亮和保存。文字和图标都使用本地样式，没有外部资源。

## 布局说明

- 文件树、标签栏和编辑区使用紧凑的分栏层级；
- 浅色与深色主题使用同一组 Fluent 强调色和中性色语义；
- 打开及切换最近工作区位于 macOS 菜单栏；新建、重命名、移动和删除从文件树右键菜单进入；
- 标题栏直接连接文件工作区，移除重复的顶部命令栏；
- 自动保存不占用常驻标签；源码切换使用菜单或快捷键。

此 HTML 是静态布局参考，不是原生窗口截图；文件树、编辑标签和 Markdown 内容以演示数据呈现。
