# maksher 界面原型说明

这份原型展示桌面编辑器的工作区布局和中性视觉方向，页面可以在浏览器中直接打开。原型会按系统颜色偏好选择浅色或深色，也可以用右上角按钮切换预览。

左侧区域包含活动栏、文件树和工作区标签；中央区域展示文档标签、编辑工具栏、所见即所得内容及状态栏。代码文件使用独立标签浏览。文字和图标都使用本地样式，没有外部资源。

## 审核重点

- 文件树、标签栏和编辑区的比例是否合适；
- 浅色与深色主题的对比度、边框和强调色；
- 工具栏是否过于显眼，所见即所得页面是否足够简洁；
- 自动保存状态、源码切换和工作区名称的呈现位置。

原生界面目前尚未完成视觉整合。此文件是审核用原型，审核通过后再将确定的间距、颜色和层级落实到 GPUI 界面。
