# maksher 界面原型说明

这份原型展示桌面编辑器的工作区布局和中性 Fluent 视觉方向，页面可以在浏览器中直接打开。原型会按系统颜色偏好选择浅色或深色，也可以用右上角按钮切换预览。

左侧区域包含活动栏、文件树和工作区标签；中央区域展示文档标签、编辑工具栏、所见即所得内容及状态栏。代码文件使用独立标签浏览。文字和图标都使用本地样式，没有外部资源。

## 布局说明

- 文件树、标签栏和编辑区使用紧凑的分栏层级；
- 浅色与深色主题使用同一组 Fluent 强调色和中性色语义；
- 工作区操作收进图标工具栏，悬停时显示中文说明；
- 自动保存状态、源码切换和工作区名称保持在内容周边。

原生 GPUI 界面已采用系统浅/深主题、Fluent 中性色和紧凑工作区图标工具栏。此 HTML 是静态布局参考，不是原生窗口截图；文件树、编辑标签和 Markdown 内容以演示数据呈现。
