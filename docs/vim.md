# Vim 模式

Velora 内置了参考 Zed 实现的 vim 模态编辑：普通、插入、替换与三种可视模式，
操作符、寄存器、宏、标记、搜索与 `:` 命令行按 vim 的习惯工作。默认关闭。

## 开启

- **偏好设置**：打开「设置 → 通用」，开启「Vim 模式编辑」。
- **配置文件**：在 `config.toml` 写入下节，重启或保存偏好后生效。

vim 的按键拦截只作用于文档编辑区；带 `⌘`（其他平台为 `Ctrl`）的应用快捷键、
侧栏、文件树与对话框不受影响。vim 关闭时按键完全直通，不做任何额外工作。

Markdown 文档按可见块组织光标：跨块的 `j` / `k`、`dd`、`yyp` 等操作以块为行，
块内文本按字符偏移处理。表格、公式、代码块等结构块按块内显示文本参与编辑。

## 配置

```toml
[vim]
enable = true
timeout_ms = 300
use_system_clipboard = true

[[vim.keymap]]
mode = "insert"
keys = "jj"
action = "esc"

[[vim.keymap]]
mode = "normal"
keys = "<leader>s"
action = "command:save"
```

| 键 | 默认值 | 说明 |
| --- | --- | --- |
| `enable` | `false` | 是否启用 vim 模式 |
| `timeout_ms` | `300` | 多键映射等待后续键的超时（50–5000 毫秒） |
| `use_system_clipboard` | `true` | 复制与删除是否同步系统剪贴板（即 `"+` 寄存器） |
| `keymap` | 空 | 自定义映射条目，可写多条 |

每条 `[[vim.keymap]]` 有三个字段：

| 字段 | 取值 | 说明 |
| --- | --- | --- |
| `mode` | `normal` / `insert` / `visual` | 映射生效的模式 |
| `keys` | 1–8 个可打印 ASCII 字符 | 依次按下的键序列；`<space>` / `<leader>` 都表示空格（leader 默认是空格） |
| `action` | 内置动作或 `command:<id>` | 内置动作：`esc` / `insert` / `append` / `visual` / `visual_line`；`command:<id>` 执行命令注册表里的应用命令，id 与命令面板一致，例如 `command:save`、`command:find_in_document`、`command:toggle_sidebar` |

非法条目（序列为空、超过 8 个键、含不可打印字符、模式或动作未知、命令 id
不存在）在读取配置时忽略并打印一行提示，其余条目照常生效。

## 支持的操作

### 模式

| 按键 | 动作 |
| --- | --- |
| `Esc` / `Ctrl-[` | 回到普通模式 |
| `i` `a` `I` `A` `o` `O` `gi` `gI` | 进入插入模式，落点分别为光标处、光标后、行首、行尾、下方新行、上方新行、上次插入处、硬行首列 |
| `R` | 替换模式 |
| `v` `V` `Ctrl-v` / `Ctrl-q` | 字符、行、块状可视 |

### 移动

| 按键 | 动作 |
| --- | --- |
| `h` `j` `k` `l` | 左、下、上、右 |
| `w` `W` `b` `B` `e` `E` | 单词或大单词的前后移动 |
| `0` `g0` `^` `$` | 硬行首、首个非空白字符、硬行尾 |
| `gg` `G` `{count}G` `:N` | 文首、文末、第 N 块或行 |
| `f` `F` `t` `T` `;` `,` | 行内字符查找与重复 |
| `|` | 跳到指定列 |
| `%` | 跳到匹配的括号 |
| `H` `M` `L` | 视口顶部、中部、底部 |
| `{` `}` `(` `)` | 段落与句子 |
| `Ctrl-d` `Ctrl-u` `Ctrl-f` `Ctrl-b` `Ctrl-e` `Ctrl-y` | 半页、整页、单行滚动 |
| `zz` `zt` `zb` | 当前块对齐视口中部、顶部、底部 |
| `Ctrl-o` `Ctrl-i` | 跳转列表后退、前进 |

### 编辑

| 按键 | 动作 |
| --- | --- |
| `x` `X` `s` `S` `D` `C` | 删除或修改字符、前一个字符、当前行 |
| `r{char}` | 替换光标处字符 |
| `~` | 切换大小写 |
| `J` `gJ` | 合并行（保留或去掉空格） |
| `gu` `gU` `g~` | 小写、大写、切换大小写（配合移动或文本对象） |
| `>>` `<<` | 增加、减少一级缩进 |
| `Ctrl-a` `Ctrl-x` | 光标处或其后的数字加一、减一（支持计数与零填充） |
| `dd` `cc` `yy` `Y` `p` `P` | 行级删除、修改、复制与粘贴 |
| `gr{motion}` `grr` | 用寄存器内容替换动作目标或整行（被替换文本丢弃） |
| `gcc` `gc{motion}` | 切换代码块内被覆盖行的行注释（按语言选择 `//`、`#`、`--`、`%` 等） |
| `u` `Ctrl-r` | 撤销、重做 |
| `.` | 重复上一次修改 |

操作符 `d` `c` `y` `>` `<` `gu` `gU` `g~` 可与移动、文本对象、可视选区组合，
支持计数，例如 `d2w`、`ci"`、`>j`、`gUiw`；`dG` / `yG` / `cgg` 按行覆盖到
文末或文首，`dj` / `dk` 包含相邻行。

### 文本对象

`iw` `aw`、`iW` `aW`、`is` `as`、`ip` `ap`，以及引号与括号：
`i"` `a"`、`i'` `a'`、`` i` `` `` a` ``、`i(` `a(`（`ib` `ab`）、`i[` `a[`、
`i{` `a{`（`iB` `aB`）、`i<` `a<`。

### 环绕

`ys{motion}{char}` 给目标加定界符，`ds{char}` 删除包围，`cs{old}{new}`
替换包围。目标可为动作、文本对象或 `s`（当前行）。支持引号 `"` `'` `` ` ``
与括号 `(` `)` `[` `]` `{` `}` `<` `>`，`b` / `B` 是括号别名。可视模式
`S{char}` 给选区加定界符；块状可视暂不支持。

### 可视模式

`v` / `V` / `Ctrl-v` 进入后可用移动键扩展选区，`o` 交换端点，`O` 交换块状
选区的角。操作符 `d` `x` `c` `y` `>` `<` `u` `U` `~` `r` 作用于选区；`gv`
重选上一次可视范围；块状可视的 `I` / `A` 在每行同一列插入；`p` / `P` 用
寄存器内容替换当前选区；`gc` 切换选中行的注释（代码块内）。可视操作后的 `.` 会按相同大小的选区
重放；块状可视暂不支持重放。

### 寄存器、标记、宏与搜索

| 按键 | 动作 |
| --- | --- |
| `"a`–`"z` `"A`–`"Z` | 具名寄存器，大写追加 |
| `"0` `"1`–`"9` `"-` `"_` `"+` | 复制、删除历史、小删除、黑洞、系统剪贴板 |
| `m{a-z}` `` `{mark} `` `'{mark}` `` `<` `` `` `> `` | 设置与跳转标记 |
| `q{reg}` `@{reg}` `@@` | 录制、重放、重复上次宏，均可带计数 |
| `/` `?` `n` `N` `*` `#` `g*` `g#` `:noh` | 搜索、重复与当前单词搜索，清除高亮；`*`/`#` 按整词，`g*`/`g#` 按子串 |
| `gn` `gN` `cgn` `dgn` `ygn` | 选中或操作下一处/上一处搜索命中；`.` 可重放带输入的 `cgn` |

`gn` / `cgn` 的命中按块内源码映射换算；跨块命中暂不参与。

### 命令行

`:w`、`:q`、`:q!`、`:wq`、`:x`、`:N`（跳到第 N 行）、`:noh`，以及替换命令
`:[range]s/pattern/replacement/[g]`，范围支持 `%`、行号、`.`、`$` 与 `N,M`。
冒号行也接受命令注册表里的命令 id（与命令面板一致），例如 `:save`、
`:find_in_document`、`:toggle_sidebar`。
