# Velora 更名与界面调整验收记录

日期：2026-09-25

## 已完成

- 应用显示名统一为 Velora；Cargo 包、可执行文件、配置目录和安装包使用 `velora`。macOS Bundle ID 为 `app.velora.editor`，Windows 安装器与图标资源已同步更新。
- 原生窗口移除重复工具栏与说明性文字，标题栏居中显示当前文件名。文件树改用 SVG 折叠箭头与更紧凑的行距；文件操作放在右键菜单，打开与切换最近工作区放在 macOS 菜单栏。
- 侧边栏可以拖动调整宽度，宽度写入偏好设置；已打开文件视图时再次点击文件图标可收起，重新点击可恢复。
- 工作区搜索同时匹配文件路径和 UTF-8 文本内容，结果显示命中行；点击内容结果会打开文件并定位到对应行。搜索在后台执行，输入变化后会丢弃过期结果。
- 代码文件使用同窗可编辑标签，使用设置中的等宽字体，并支持语法高亮、撤销、保存与原换行风格保留。

## 尚待验收

- 当前 macOS 处于锁屏状态，原生窗口只能捕获到舞台管理器缩略图；最终原生截图需要解锁后补拍。仓库中的旧原生截图属于界面重构前记录。
- Windows 安装器尚未在 Windows 实机运行。
- 按既定开发优先级，本轮没有做整机启动速度、大文件打开时间或输入延迟测量。
