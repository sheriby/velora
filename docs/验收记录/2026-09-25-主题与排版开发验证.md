# Velora 主题与排版开发验证

日期：2026-09-25

## 本轮完成

- 新增 Paper、Forest、Midnight、Ink 四套内置主题，与 Velora 浅色、深色及系统跟随一起提供；主题列表显示正文底色、文字色和强调色色卡，自定义主题也可预览。
- Markdown 正文默认跟随主题字体；Paper 与 Ink 在 macOS 使用宋体。用户明确选择的字体优先，旧版主题文件继续按系统字体读取。
- 主题提供默认写作列宽；设置页可改为 640、760 或 900 像素，窄窗口仍按可用宽度收缩，代码标签页保持宽布局。
- 所见即所得视图按标题级别留出不同的段前空间，缩小标题后的正文间距与连续列表项间距；源码视图保持均匀间距。
- 原生“视图”菜单新增专注模式与打字机模式。两者只影响当前窗口的显示和滚动，不写入 Markdown 文件。
- 注释块、任务复选框及滚动条的中性色随主题变化。
- 侧栏“文件、搜索、大纲”入口改用统一尺寸的 SVG 图标；搜索提示明确包含文件内容搜索。

## 尚待验收

- 当前远程图形会话中，新旧 Velora 安装包都只暴露 106×103 的缩略窗口，无法获得实际原生窗口截图。由此不能判定新版视觉效果是否达到[界面原型](../design/界面原型-最新.png)；需要在可操作的桌面会话中补拍并审核。
- macOS 安装包尚未签名或公证，仅供本机与小范围内部试用。
- Windows 初版按既定计划延后正式发布；此前的交叉构建产物未在 Windows 实机运行。
- 冷启动、1 MB/10 MB 打开时间及输入响应阈值尚未在当前版本测量。

主题细节与后续原生视觉检查项目见[主题与长文排版](../design/主题与长文排版.md)。
六套主题还提供[静态预览图](../design/主题预览.png)，仅用于颜色与排版方向审核。
