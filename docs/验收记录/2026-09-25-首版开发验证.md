# maksher 首版开发验证记录

日期：2026-09-25

## 验证环境与边界

- macOS 开发机，Rust 1.88，GPUI 0.2；
- 所有构建均使用 fastdev 或测试 profile，没有使用 release profile；
- Windows 目标为 x86_64-pc-windows-gnu，通过 macOS 交叉编译并生成内部 NSIS 安装器；
- 当前执行环境无法读取桌面显示器截图，因此未声称已经完成原生窗口的截图视觉评审。

## 已通过的构建

| 项目 | 命令或证据 | 结果 |
|---|---|---|
| macOS 开发检查 | cargo check --profile fastdev | 通过 |
| macOS 应用启动 | cargo run --profile fastdev -- . | 进程成功启动 |
| macOS 内部安装包 | scripts/package-macos.sh | 退出码 0；生成 maksher.app 和 maksher-0.1.0.pkg；包展开后包含可执行文件、Info.plist 与图标 |
| Windows x64 交叉编译 | cargo build --profile fastdev --target x86_64-pc-windows-gnu | 通过；产物识别为 PE32+ GUI x86-64 可执行文件 |
| Windows 内部安装器 | scripts/package-windows.sh | 退出码 0；生成 NSIS 自解压安装器 |

macOS 安装包未签名或公证，仅供本机和小范围试用。Windows 安装器尚未在 Windows 实机运行。
