# Velora 首版开发历史验证记录

日期：2026-09-25

本记录保留界面重构前的构建与测试结果。代码文件现已改为同窗可编辑标签；当前界面、菜单和测试结果以新的验收记录为准。

## 验证环境与边界

- macOS 开发机，Rust 1.88，GPUI 0.2；
- 所有构建均使用 fastdev 或测试 profile，没有使用 release profile；
- Windows 目标为 x86_64-pc-windows-gnu，通过 macOS 交叉编译并生成内部 NSIS 安装器；
- 静态 HTML 原型已用无头浏览器渲染并检查浅/深色布局；当前原生窗口截图见[新版界面截图](2026-09-25-velora-macos-原生界面.png)。
