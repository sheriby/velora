# v0.2.2

本版把「选中文字之后要做的事」补齐到就近的入口：正文右键菜单从只有「插入表格」一项扩成顶部一排图标加六个长行（其中三行是「格式」「段落」「插入」二级面板），选中文字后在选区上方浮出一行九格的格式工具栏，命令面板新增「编辑」「格式」两档共 12 条可执行命令。这三处与既有键位调的是同一批函数——一个动作只有一处实现，四个入口（键盘、右键菜单、选中工具栏、命令面板）不会在某一次改动后各长出一份行为。同时修掉「打开着的那一篇被环境的动作重来一遍」这一族问题：外部改动重载与切换标签都保留视图模式、视口与光标；预览标签在第一次编辑时转为固定，未落盘的文档点亮标签圆点；`[editor] autosave` 开关把外部改动检测与自动落盘分开；自动保存或 ⌘S 撞上外部改动时给出「重载磁盘版本 / 另存为… / 继续编辑」三个解除入口。对用户的直接结果是——改格式、换段落种类、插一块新内容不再需要先翻键位表；文档不会因为一次外部写入被弹回顶部或换成另一种视图。

## ✨ 新增

**正文右键菜单**

- 形状为「顶部一排图标 + 六个长行」：图标条是撤销、重做、剪切、复制、粘贴、粘贴为纯文本六颗，组之间一条竖线，格子上不带文字，键位写进悬停说明；长行是复制为 Markdown、复制为 HTML、「格式」「段落」「插入」三行二级面板与切换源码模式。每一行前置一枚描出来的图标，置灰时图标与文字一起变灰。实测主面板从 389 高收到 234 高、宽 229。
- 「格式」档十行：八种行内样式加链接、清除格式。「段落」档十二行：标题 1–6、正文、无序 / 有序 / 任务列表、引用、代码块。「插入」档七行：表格、图片、代码块、公式块、分隔线、目录、Front Matter。
- 面板尺寸与落点同源：宽度按这一列最宽的一行估算（含图标列、面板内边距与边框），落点按这份尺寸夹紧在视口内，贴边时越界的一侧往窗口内收，二级面板翻到主面板左侧。
- 右键时保住已有选区；不可用的行仍然占位，只是变灰——行序与行高在有无选区之间逐行相等。

**选中工具栏**

- 选中文字后在选区外接框上方 8px 浮出一行九颗格子：「段落」下拉加粗体、斜体、下划线、删除线、行内代码、标记文本、链接、清除格式；放不下时翻到下方。只在抬手之后出现，拖动过程中不出现；整段选区滚出视口时收起，右键菜单、命令面板、快速打开开着时让位。
- 「段落」下拉的行数据直接读右键菜单那一份，置灰口径、行名与文字三处跟着菜单走。格子的悬停说明是「动作名 + 当前生效的键位」。

**行内格式与段落**

- 八种行内格式与链接的入口提到编辑器层：跨块选区按可见块逐段处理，只开一个撤销组，一步撤销把改过的块一起放回。
- **标记文本 `==文字==`**：编辑态与显示态都铺底色，进入源码态时光标走进那段会显出两个等号，HTML / PDF / PNG / 打印导出成 `<mark>`。
- **清除格式**只剥选区里那一段的行内样式记号，链接与 HTML 行内样式不动；选区里没挂样式时格子与菜单行都置灰，悬停说明写出原因。
- 段落种类转换覆盖标题 1–6、正文、无序 / 有序 / 任务列表、引用、代码块；同一目标再点一次是取消（任务项再点一次只去掉复选框）。换进列表时抄同族邻项的记号，邻项写 `+` 新项就跟着写 `+`。
- 换种类与插入都按区段写回字节，只覆盖涉及的那几块与其接缝，没碰过的行逐字节原样——Setext 标题不会被拼成 `# `，邻居的列表记号不会被洗成 `-`。

**插入与剪贴板**

- 「插入」七类块各自一条命令、一步撤销；插完把光标交给新块（代码块落在围栏里那一行、公式块落在开栏之后、Front Matter 落在两条 `---` 中间）。图片走原生选择器，与拖放共用同一条落点入口。
- 粘贴为纯文本 ⌘⇧V 不读剪贴板的 HTML 味道，也不把选中文字后的网址包成链接；其余分支（跨块替换、表格单元、多行拆块）与 ⌘V 完全一致。
- 复制为 Markdown ⌘⇧M 取的是文件里的那几个字节（`**加粗**` 还是 `**加粗**`），与「复制」取渲染后的可见文本是两种内容来源。复制为 HTML 沿用既有入口，现在在菜单里点得到。

**命令面板与键位**

- `Edit` 与 `Format` 两档共 12 条命令进面板；按回车与点一行是同一个收尾，查询筛选之后回车执行筛后那一条，查无命中时回车既不动文档也不收起面板。
- 补齐的默认键位（都能改绑）：

| 命令 | macOS | Windows / Linux |
| :--- | :--- | :--- |
| 删除线 | `⌘⇧X` | `Ctrl+Shift+X` |
| 上标 / 下标 | `⌘⇧=` / `⌘⇧-` | `Ctrl+Shift+=` / `Ctrl+Shift+-` |
| 标记文本 | `⌘⇧H` | `Ctrl+Shift+H` |
| 清除格式 | `⌘\` | `Ctrl+\` |
| 链接 | `⌘K` | `Ctrl+K` |
| 插入图片 | `⌘⇧I` | `Ctrl+Shift+I` |
| 粘贴为纯文本 | `⌘⇧V` | `Ctrl+Shift+V` |
| 复制为 Markdown | `⌘⇧M` | `Ctrl+Shift+M` |

- 菜单与工具栏右侧那一列读的是**当前生效**的键位：偏好页把加粗改成 `⌥⌘B` 之后，屏幕上跟着换，改绑与其他命令撞车而被退回默认键的那些也如实显示默认键。

**标签、现场与落盘**

- 外部改动重载与标签切换都保留每篇文档的视图模式、视口偏移与光标位置；现场按 `DocumentView` 交还给导入流程，而不是在每个入口前后各做一次快照恢复。
- 搜索结果行、文内链接与 wikilink、⌘P、正文本地链接四个浏览入口只占一个预览位；预览标签在第一次编辑时转为固定。
- 标签圆点表示「这篇还没落盘」，正在编辑的那一篇也点，自动保存写入后熄灭。
- `[editor] autosave`（默认开）落在偏好设置「文件」页。关掉之后编辑不写盘，但外部改动检测与恢复快照照跑——检测与写入是两件事，短路整条后台任务会连带把检测也关掉。
- 外部改动冲突的解除框给出「重载磁盘版本 / 另存为… / 继续编辑」，自动保存撞上与 ⌘S 撞上两种撞法共用同一个框；按「重载」前先把当前内容写进恢复快照，不丢没落盘的编辑。

## 🐛 修复

- 文档被外部更新后源码模式自动跳到所见即所得、页面回到顶部、光标丢回开头；切换标签同样丢这三样。
- 源码模式的光标快照固定读第一根投影块的块内偏移，光标落在第 2 块之后把落点说成文件开头。撤销、切视图、重载三条链路共用这一处，因此三条一起修好。
- 交还源码态时块树仍按 markdown 解析建根，行号换算在不带行首的块起点上断言失败（实测报「偏移落在多字节字符中间：1161」）；快照偏移劈开一个汉字导致同一族 panic。选区落地前统一退回字符边界。
- 编辑过的预览标签切走时被当成干净预览销毁；未保存圆点不亮正在编辑的那一篇。
- 关掉自动保存会连带失去外部改动检测。
- 冲突只在文件树面板留一行红字、没有可点的出路；⌘S 撞上的那块框只有「好」一个按钮。
- 在没聚焦的段落里按下拖动选不出文字，必须先单击把光标落进去。
- 打字开出的空公式块当场是一块，存盘重开散成两块原始 markdown。
- 命令面板点一行与按回车是两条路，且回车那一条此前根本不存在；命令面板借走窗口焦点时，块级命令收不到派发（实测派发路径停在面板输入框，块不在路径上）。
- 选中工具栏浮在命令面板与快速打开的遮罩之上。
- 菜单与工具栏的面板宽度漏算面板内边距与边框（内框比最宽那一行窄 10px），中英文长标签截字；主面板高度漏算上下边框，屏上 389 与算出 387 不一致，落点按错值夹紧后菜单比预期低 2px。
- 二级面板顶部比父行低 8px（行顶起始值把面板的下内边距重复算了一次）。
- 图标条六颗按自然宽度挤在左半、右边空一截。
- 文件树与标签右键的行高与内边距硬编码 32px / 10px，与正文菜单的 28px / 8px 不一致，两套浮层看着像两个产品。
- 清除格式在没挂样式的选区上点下去毫无反应。
- 换种类逐块写回时，列表项换成标题会吞掉接缝那行空行，写下去的字节读回来少一根块。
- 「插入表格」的旧点击处理器在菜单换行之后没有消费者；`reveal_command_spec` 在测试侧另有一份副本，改一处漏一处。

## ⚠️ 语义变化

- 「拷贝」在菜单与文档里统一改口「复制」；`Copy` 与 `Copy as Markdown` 的差别只在内容来源，名字此前是两处各自起的。i18n 键名不变，用户自己的语言包仍然覆盖。
- 右键菜单去掉「全选」那一行；⌘A 那条「一次选本块、再下一次选整篇」的循环照旧，命令面板与偏好页仍有它。
- 撤销、重做、剪切、复制、粘贴、粘贴为纯文本六行从长行改成顶部图标条，代价是键位从右侧那一列挪进悬停说明。
- 「格式」「段落」「插入」三块二级面板不带图标：那一档读的是条目名，加图标只会把每行拉宽。
- 预览标签的转正点是「第一次变脏」；点击标签栏只是激活，不转正。会话文件不记 `preview`，重启后一律按固定标签恢复。
- `autosave = false` 时脏标记不再自动清除，圆点长亮到 ⌘S 或关闭时保存为止；⌘S、关闭时的批量保存与导出前的另存都不看这个开关。
- 冲突框的默认项是「重载磁盘版本」，Esc 等价于「继续编辑」。选「继续编辑」时冲突记录、脏标记与自动保存停摆都保留——解除只有重载与另存为两条路。
- `==` 成为行内语法：正文里成对出现的字面 `==`（例如 `1 == 2 and 3 == 4`）会被读成标记文本；没配对的单个 `==` 仍是字面。这是引入新语法的代价。
- 上标与下标写出 `<sup>…</sup>` / `<sub>…</sub>`，不改成 `^x^` / `~x~`（后者的读入路径本来就有）。
- 有序列表的序号由所在列表组重算：`5. 甲` 那种从 5 起跳的写法不保留起始号，起始号在解析时没有副本。
- 段落与插入两档没有默认键位——标题的 ⌘1–6 与切换标签的 ⌘1–9 撞车（那九条是固定绑定，不进取替表）；这两档同样不进命令面板，搜得到却按不动比搜不到更难看。撤销、重做、剪切、复制、粘贴五条也不进面板。
- `<mark>文字</mark>` 不吸收成标记文本样式：序列化只会写 `==`，吸收等于改掉用户没碰过的字节。

## 🧪 测试与可靠性

- 测试数 1393 → **1525 通过 / 0 失败 / 6 ignored**，编译零警告；本支改动 112 个文件、+11 907 / −580 行，42 笔提交。
- 新增十个测试模块：`inline_format`、`paragraph_kind`、`document_context_menu`、`selection_toolbar`、`insert_blocks`、`link_insert`、`insert_image`、`clipboard_text`、`clear_format`、`palette_commands`。本仓此前没有任何键盘行内格式与菜单换块种类的用例。
- 断言落在三类可核对的对象上：缓冲区字节逐条比对；写下去的字节重新读一遍比块树（种类序列必须与当前树一致）；真实事件路径——右键按下、按下—拖动—抬手、`simulate_keystrokes`——配 `debug_bounds` 取到的行顶、面板边界与图标格子的贴边。
- 面板宽度不再按算式自证：用 `window.text_system().shape_text` 量真实字体宽度，与屏上面板内框比，中英文各核一次。这条守卫当场撞出高度漏算边框那一处。
- 每笔改动都做了故意改坏验证，改前红值记在提交正文里（例如区段起点少带前一块接缝时红在 `left: "- 项甲\n## 项乙\n\n正文丙\n"`）。
- 墙钟预算类闸门（`ten_mib_typing_does_not_scan_the_whole_document` 等）在多任务并发时会假红：单跑均通过，同一份代码重跑整跑全绿，据此判为抢 CPU 而非回归，未放宽预算。

## ⚠️ 已知限制

- 源码模式下的右键沿用原生编辑行为，不弹这套菜单；代码块与表格格子上也不弹。从代码块退出来走工具栏那一行或键位。
- 标注（`> [!note]`）不参与段落种类转换：它自己是容器（头部加子块），换出去要先安置子块并重记空行账。带子块的父项换出列表那一族只置灰，不自动拆父子——拆父子会改根块序列，区段写回的接缝归属不再成立。
- 跨两行的引用只允许换成正文或取消引用，换标题与列表会读回成两根块。
- 代码块退回正文时语言信息串随围栏行一起收掉，不留副本。
- 行内样式的嵌套先后不记忆，按栈序规范成 `**==x==**`。
- 菜单不支持方向键导航；图标条上不放文字标签，悬停说明也没有常驻小标签。
- 表格轴菜单与图片菜单的落点仍直接用右键坐标，没走正文菜单那套夹紧，贴边会溢出窗口。
- 清除格式不剥粘贴进来的 `<span style=…>` 那一族 HTML 行内样式；工具栏那一排是六种常用行内样式加链接、清除格式与「段落」下拉，不含上标与下标。
- 快捷键列只显示每条命令的主按键，一条命令绑多串键时备用那颗不在屏幕上铺开。
- 本支的界面结论全部来自 gpui 测试的真实布局与字节断言，未在构建出的实机上逐项手点。13 枚图标的形状靠系统 QuickLook 栅格化后逐张核对，落进菜单与工具栏之后的观感、深浅主题下的实际显示、以及英文长标签下的面板宽度仍以实机为准。
