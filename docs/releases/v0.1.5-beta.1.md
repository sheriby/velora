# v0.1.5-beta.1

一次纯内部质量版本：把仓库里所有超过 1000 行的源文件按职责拆分为子模块，功能与 v0.1.4 完全一致（纯移动重构，函数体零改动）。发布产物、快捷键、配置格式均无变化。

## ✨ 新特性

- 无。本次为内部重构版本，面向用户的行为与 v0.1.4 完全一致。

## 🐛 修复

- **测试基建**：修复 5 个一直失败的测试——macOS 上 `/var` 是 `/private/var` 的符号链接，4 个依赖临时目录路径比对的测试（watcher 刷新文件树、脏文件搜索跳转、反链外部拾取、代码文件索引）断言永不成立；2 个性能预算断言的阈值按真实机器波动重新校准。
- 清理全部构建与测试警告（重复的 `#[test]` 属性、未用导入等）。

## ⚠️ 破坏性变更

- 无。发布产物与配置格式不变。

## 📝 其他

- **文件组织约定**：除两个单函数渲染文件（`editor/render/paint.rs` 的 `Render::render`、`block/render/paint_parts.rs` 的 `Element::paint`）外，所有源文件收敛到 ≤1000 行；测试与源码分离，统一放 `<name>/tests.rs` 或 `<name>/tests/` 目录。约定已写入 `docs/architecture/overview.md`。
- **拆分明细**（纯移动，由编译器与 1069 项测试双重守门）：
  - `workspace.rs` 10013 行 → 根 + 17 个子模块（标签页/会话监听/右键菜单/侧栏/查找替换/文件树操作/搜索后缀/输入处理等）+ 7 个测试文件
  - `editor/tests.rs` 8662 行 → 20 个主题测试文件 + 共享脚手架 `common.rs`
  - `runtime/tests.rs` 3267 → 9 个主题文件；`events.rs` 4930 → 根 + 6 个子模块 + 6 个测试文件；`document.rs` 4466 → 根 + parse/import/blocks + 6 个测试文件
  - `preferences.rs` 4717 → 根 + persistence/window/widgets/两个设置页/render + 测试；`inline.rs` 4696 → 根 + tree/parse/links/delimiters/stacks；`theme.rs` 2932 → 根 + de/presets/manager_parts；`i18n` 3231 → 根 + 7 个子模块；`element.rs`、`app_menu.rs`、`interactions.rs`、`runtime/mod.rs`、`export/html.rs`、`context_menu.rs` 等同步收敛
- `docs/architecture/` 六个分册已更新为拆分后的模块地图与文件组织约定。
