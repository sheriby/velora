# Velora v0.3.0-beta.1

这是一版界面重构的预发布：整个应用的外壳改用 GPUI Kit 的组件重搭——标题栏、标签、侧栏、状态栏、右键菜单、命令面板、偏好设置、对话框与提示都换成同一套标准控件，键盘操作与辅助技术读到的语义随之统一。同时补上网络代理设置，并修掉迁移过程中暴露的一批界面与跨平台缺陷。

| 平台 | 文件 | 说明 |

## ✨ 新增

**界面外壳统一到 GPUI Kit**

- 文档标签、标题栏按钮、状态栏与面板分隔条改用标准控件：拖拽、双击改名、右键菜单和中键关闭的行为不变，键盘可达性与焦点顺序按控件规范统一。
- 侧栏导航、文件树、大纲、搜索结果与 AI 对话列表改用统一的列表组件：悬停色、选中态与滚动条一致，长列表的滚动位置在切换面板后保持。
- 命令面板、快速打开与搜索框改用统一输入框与候选列表：输入法组合、上下键选择与回车执行的时序统一，关闭后不再残留候选状态。

**菜单、对话框与提示**

- 表格与图片的右键菜单、工作区与标签的右键菜单改用标准菜单组件，靠近窗口边缘时自动避让并保持完整可见。
- 未保存确认、文件打开方式、错误提示与更新提示改用标准对话框与消息框，主按钮顺序与快捷键在各平台一致。
- 偏好设置窗口改用标准表单与分组：字段在窄窗口与大字号下自动改为上下排布，保存失败的反馈固定在底部可见。
- 偏好设置的分组内部为相邻设置项补上浅色分隔线，一屏多行不再挤成一整块。

**网络代理**

- 偏好设置 → AI 页新增「网络代理」：支持 `http://`、`https://`、`socks5://`，填写后 AI 端点请求、更新检查与安装包下载、正文里的远程图片都走这个代理；留空则沿用系统设置与 `HTTPS_PROXY` 等环境变量。
- 保存后立即生效，不需要重启；代理地址写错时按直连处理并在终端留下说明，不会让网络功能整体失效。

**编辑区控件**

- 选区工具栏、公式编辑器控件、公式补全候选、文件历史浮层与表格追加行列按钮改用标准按钮，焦点提示与工具栏其它按钮一致。
- 正文右键菜单的「复制」在没有选区时复制光标所在的那一行。

## 🐛 修复

- 选区工具栏里的 `</>` 与「清除格式」字形被切掉一半：标准按钮会给带内容的按钮补左右内边距，26px 的格子实际只剩 14px，现已改为按整格排版。
- 置灰的菜单项与可用项几乎同色：整屏不可用的「格式」二级菜单看起来像「没有悬停反馈」，现在置灰项明显更淡，可选与不可选一眼可分。
- 文件树的字号与字色改为与侧栏其它文字同档、同色系，满屏目录不再又大又重。
- 更新提示在窄窗口或大字号下说明区会被压成零高、按钮被挤出卡片：说明区保底两行，卡片高度按实际可用空间计算。
- 预览浮层打开后接管键盘焦点，`Esc` 关闭并把焦点交回原来的正文块。
- 块内公式预览不再固定预留三行空白，无预览时正文不跳。
- Windows 构建因使用了未声明的日志宏而失败，现已改为与应用其它地方一致的可见日志。

## ⚠️ 语义变化

- 正文右键菜单的「复制」：没有选区时复制光标所在行，不再置灰。剪切与行内格式仍然只认选区。

## 🧪 测试与可靠性

- 本版 121 笔提交，402 个文件，+49458 / −94600 行。
- `cargo test --bin velora`：2615 通过、0 失败、54 忽略；CI 三个平台（macOS ARM64 / macOS Intel / Windows x64）的默认用例与慢用例全绿。
- 新增守卫：置灰菜单项的亮度差按阈值断言；`file:` URL 的盘符写法必须解出不带前导斜杠的路径（Windows 上真红）。

## ⚠️ 已知限制

- 本版为预发布：界面迁移后仍有少量自绘菜单未替换（正文右键菜单与选区工具栏的下拉面板），它们与新控件的焦点样式存在细微差异。
- Windows 专属代码（剪贴板 HTML 读取）本地无法编译验证，依赖 Windows x64 的 CI 任务把关。
- 深色模式下的 Mermaid 图表仍用图表库自带的深色配色，未跟着应用主题取色；预览浮层的画布底色已跟随主题。
