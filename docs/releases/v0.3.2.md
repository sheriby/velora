# Velora v0.3.2

本版把 v0.3.1 引入的 Vim 模式按评审逐条修到与 Vim 对齐，新增可在浏览器里直接打开的网页主题编辑器，并给 AI 助手补上图片上下文、历史管理、会话级连接切换与「继续生成」。AI 的资料边界与控制面写入同时收紧：敏感文件默认拒绝读取，Skills 与 CI 配置不再由模型改动。

## ✨ 新增

- **网页主题编辑器**：`tools/theme-editor/index.html` 用浏览器直接打开，不起本地服务、不打包进应用。六个内置主题的全部 token 可改，提供文档与界面双预览、单项/分组/全部重置、主题包与裸 `Theme` JSON 导入；导出格式与应用的自定义主题导入一致，可直接交回应用。界面中英文可切换。
- **AI 图片上下文**：输入框的图片按钮承接最多 5 张 PNG/JPEG/GIF/WebP，单张上限 8 MiB，已选图片以可删除的标签显示；图片随消息发送并写进历史与运行检查点。
- **AI 历史管理**：历史条目可重命名、置顶、按标题搜索，也可导出为未命名 Markdown 标签继续编辑；置顶条目排在前面并带星号。列表底部显示条数与磁盘占用，标题栏的清理按钮按最近时间保留 50 条，置顶记录永久保留。
- **会话级连接切换与用量显示**：输入框左侧显示本轮使用的连接，点击循环切换，不改全局默认；完成一轮后显示 ↑输入 / ↓输出 token。
- **草稿持久化**：输入随写随存进会话，还原历史时草稿一并回填。
- **继续生成**：模型因输出上限被截断时给出提示，并提供「继续生成」按钮在原草稿后续写。
- **资料边界可见**：资料面板顶部列出本轮会发送的来源或全文范围、已启用 Skills 数量、上下文预算与显式排除项；草稿里激活的 Skills 显示在输入框上方。
- **@ 引用按工作区搜索**：打开资料面板时后台载入工作区文本文件名单（上限 5000 条），输入即按大小写不敏感子串过滤，已选引用始终可见。
- **AI 入口补齐**：正文右键与选中工具栏的 AI 二级菜单追加「问 AI」；代码文档也能打开助手，提议的审阅预览按文件类型渲染。
- **只读提示**：只读文档或阅读任务里，AI 标题栏显示「只读不能接受修改」。
- **欢迎页第二入口改为「打开文件夹」**：Markdown 工作区通常以目录为单位，不必逐篇打开。
- **非本机 HTTP 提示**：连接表单对非回环的 `http://` 地址提示 API Key 与正文会明文上车，本地服务不受影响。

## ⚡ 性能

- Vim 的块内编辑（`x`、`dw`、`~`、`r`、注释切换、块状复制的补插入等）改为按区间写回缓冲区，不再每键整篇序列化；实测四键由 4 遍整篇序列化降到 0。
- AI 工具的分页读取按文档缓存行起点索引，跨页的行号与总行数走二分，连续翻页由 O(n²) 降到接近 O(页大小)。
- 接受提议时的窗口冲突检查不再克隆所有标签正文，只比较规范路径与脏标记。
- 检查点事件内直接重建审阅投影，不必等下一帧渲染。

## 🐛 修复

**Vim 模式**

- 左向动作的操作符（`db`、`d0`、`d^`、`dF`、`d{`、`d(`、`dge`、`yb`、`c0`）不再空操作，寄存器内容与实际删除一致。
- `v d` 删除光标处字素；`viw`、`vi"` 不再多选一格；引号文本对象不跨两个字符串配对，转义引号按字面处理。
- 句子动作 `(` 与 `)` 落在句首非空白处，并越过连续的 `!?`。
- `d2d`、`>2>`、`3gJ` 这类「操作符 + 计数」与「计数 + 动作」组合生效。
- `2>>`、`V j >`、代码块的 `>>` 与 `<<` 按区间覆盖的每条硬行落笔。
- 行级复制保住第二硬行的行内记号，紧邻列表项与连续引用的原始分隔不被换成空行。
- 块末与行末的 `r`、`~` 不再空操作；行末 `2r` 不越行插字。
- 块状可视的 `o` 与 `O` 不再把矩形塌成一列；块状 `>` 与 `<` 按整级增删，`y` 与缩进不再覆盖无名寄存器与系统剪贴板。
- 只读文档里的编辑命令不再动寄存器与剪贴板，导航与复制保持可用。
- 普通与替换模式下鼠标只移动光标，双击不会再在非空选区上被一个字符整段替换。
- `Ctrl-a` 递增光标所在的整段数字；`Ctrl-[` 认作 Esc；插入模式的 `Ctrl-r` 把行级寄存器当打字打进光标处。
- 递归宏不再把进程打崩，按 Vim 的口径直接不动作。
- `:wq`、`:x`、`ZZ` 先落盘再关页，不再弹出未保存确认后把这次写盘丢掉。
- 跳转表可前进，`/`、`n`、`N`、`*`、`#` 的跳转也入表，`Ctrl-o` 能回到搜索前。
- `:s` 的替换串支持 `&` 与 `\1`–`\9`；`/` 不再借用搜索面板的正则与模糊开关，命中高亮与 `:noh` 按 vim 自己的开关工作；命令行可用 ↑/↓ 回溯历史，失焦自动收起且不再被选中工具栏压住。
- 组词期间 Enter 与 Esc 留给输入法；语言框与公式/双链补全浮层先于 vim 拿键。
- 光标移动、大小写与替换按字素簇步进，ZWJ 家族表情与组合字符不再被切开。

**AI 助手**

- 还原历史会话会先切回它所属的文档，列表里也标出文件名；在浮窗里翻历史不再把面板变成侧栏。
- 失败轮重试同时截断模型历史，不再把失败那一轮的用户要求留给模型。
- 资料范围与排除项按规范化路径比较（`./` 前缀、大小写、符号链接别名都算同一个文件）；`.env*`、私钥、`.ssh`/`.aws`/`.gnupg` 与凭据文件默认拒绝读取。
- AI 不能再写入 `.velora`、`.git` 与 `.github/workflows`；助手面板保存设置前比对磁盘，冲突时提示重新打开而不是覆盖偏好页的改动。
- 工作区外的文档用与内容无关的稳定短哈希做 id，本机绝对路径不再发给模型；另存或恢复后的标签仍能被来源定位。
- 停止任务后工具记录不再停在 Running，检查点不再把取消令牌带回界面；新建文档的提议重置后可以再次提议。

**界面与工具**

- 网页主题编辑器快照的衬线字体统一为 Georgia，Windows 上重新生成不再与 macOS 提交的版本冲突。

## ⚠️ 语义变化

- Vim 普通与替换模式下鼠标只移动光标，双击选词只在插入模式；要选词请按 `v`。
- Vim 在只读文档里可导航、可复制、不可改；编辑命令不再写寄存器与系统剪贴板。
- AI 不再能修改 `.velora/skills`、`.git` 与 `.github/workflows`；敏感文件默认拒绝读取，此前能通过别名读到的路径现在会被拒。
- AI 历史清理保留最近 50 条与全部置顶记录，其余从当前工作区目录删除。
- 失败轮重试会让会话文件里的模型历史变短，这是本版修复的一部分。
- 会话文件新增字段（所属文档、标题与置顶、草稿、用量、附件），旧文件按默认值读取，无需迁移。
- 工具返回新增 `offset`/`next_offset`/`limited` 与 `total`/`truncated` 字段。

## ⚠️ 已知限制

- Vim：`G` 仍落在末块首行，`H`/`M`/`L` 与 `Ctrl-d`/`Ctrl-u`/`Ctrl-f`/`Ctrl-b` 仍按块移动，`Ctrl-e`/`Ctrl-y` 按固定步长滚动；要接视口几何需要另开一笔。
- Vim：点重复的素材仍由记录的按键序列生成，`R` 模式不放行输入法。
- Vim：`:s` 替换串不支持 `\u`、`\U`、`\l`、`\L` 大小写翻转；模式侧仍是 Rust regex 口径。
- Vim：命令行组合态（拼音未上屏时的 Enter/Esc）无法在测试里驱动，只有代码路径核对。
- AI：图片以 base64 写入会话历史，带图会话的体积显著增加；提供方不支持 vision 时按服务端错误展示。
- AI：任务运行中追加的 `@引用` 仍会被静默丢弃。
- AI：资料面板的文件名单上限 5000 条，未选候选最多显示 300 条。
- 编码：无 BOM 的 UTF-16 不做猜测、拒绝打开；Big5/Shift-JIS 等恰好是合法 GB18030 的旧编码按 GB18030 打开。
- 搜索：正则模式仍忽略 fuzzy；非法正则退化为字面搜索；模式不能跨行。
- AI 浮窗仍只能在主窗口内移动，暂不支持移出窗口。
