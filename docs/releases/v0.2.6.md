# v0.2.6

支持直接预览图片文件，新增界面、正文与代码的独立字体设置和一步选择全文的命令。修复编辑过程中空链接消失、行内样式输入跳位、公式编辑丢失相邻内容，以及 Markdown 解析、编码保存和导出不一致的问题。侧栏保留文件树、搜索与大纲，移除标签功能和反链面板，双链打开、创建与补全继续可用。

## ✨ 新增

**图片文件预览**

- 文件树、打开文件、快速打开、最近文件和启动参数支持图片预览，包括 JPG/JPEG、PNG、WebP、ICO 等渲染器支持的格式。
- 图片按窗口空间适配显示，状态栏展示尺寸，文件树使用图片专用图标。
- 图片以只读标签打开，支持临时预览、固定与关闭；切换图片保留文档的未保存内容，文本保存命令不会覆盖图片文件。
- 已打开图片发生外部修改时刷新预览；真正解码失败时显示应用内错误提示。

**字体、选择与侧栏设置**

- 从系统已安装字体中分别选择界面、正文和代码字体及字号，保存后刷新打开的窗口。
- 新增「选择全文」命令，默认快捷键为 macOS `Cmd+Shift+A`、Windows `Ctrl+Shift+A`，应用菜单、命令面板和快捷键设置均提供入口。
- 侧栏全局记住开关状态和上一个非搜索面板；启动设置可选择跟随上次、固定打开或关闭，以及固定文件树或大纲。

## 🐛 修复

**编辑与导航**

- 输入 `[]()` 时空链接不再消失，可以继续填写标题与地址。
- 在成对标记中连续输入时，光标不再在首字后跳到标记外；例如在 `**` 的两个星号之间输入 `test`，完整单词保持在原有样式内。
- 每张图片首次解码前不再闪出一行文字占位。
- 点击空文档和正文末尾下方的空白可以进入编辑并将光标落到文末。
- 长源码文档首次量高后，滚动条进度与实际内容位置保持一致。
- 字体等设置的下拉菜单不再撑高页面，滚动菜单不会同时滚动底下的设置页面；切换设置页或其它下拉框时正确收起菜单。
- 快捷键设置采用紧凑分组与当前平台的默认键位展示，录制、取消和重置状态更清楚。
- `file:` 链接保留正确的绝对路径，重复标题的带序号锚点可以在应用内跳转。

**Markdown 与公式**

- UTF-16 文件按编码实际解码，保留 BOM 和行尾形状；带 BOM 的首行标题能够正常识别。
- 代码围栏按 CommonMark 的长度规则闭合，有序列表保留原文起始编号，反斜杠转义和行尾硬换行按统一规则处理。
- 表格单元格保留原文反斜杠，`<br>` 显示为换行。
- 块公式闭合后的文字、同块相邻公式和公式内部空行得到保留；多行公式正确识别关闭符。
- 公式弹窗只替换目标公式，保留同块其它内容；应用或取消后恢复正文焦点，未修改草稿保留原文。
- 明确的 `\(...\)` 公式定界符不再被金额规则跳过，阅读与导出的金额、公式判据保持一致。

**保存、导出与更新**

- 后台和已关闭标签按原文件编码与行尾保存，采用原子写入，读盘失败与复查失败留下可见原因。
- 外部修改检测比较内容，同尺寸、同修改时间的文件变化也能刷新。
- HTML、复制为 HTML、PDF、PNG 与单文件导出共用 Markdown 解析后的结构；代码段、链接目标和嵌套引用不再被行级预处理误改。
- 导出标题带可跳转的锚点，重复标题、中文与 emoji 标题保持稳定；`[TOC]` 展开为目录，提示框保留类型和自定义标题。
- 本地图片路径、尖括号和百分号编码使用统一解析规则，拖入、粘贴、阅读与导出的图片格式范围保持一致。
- 启动自动检查更新失败只记录日志，避免网络异常弹窗；手动检查仍保留结果提示。

## ⚠️ 语义变化

- 侧栏开关和面板选择改为全局记忆，搜索不覆盖面板记忆；侧栏宽度继续按工作区记忆。
- 既有 `Cmd/Ctrl+A` 的分段选择行为保留，一步选择整篇使用新增的「选择全文」命令。
- HTML 导出改为基于统一 Markdown 解析结果生成，标题、目录和提示框的输出结构有所变化。

## ⚠️ 破坏性变更

- 移除标签侧栏、标签聚合计数、井号词点击搜索和标签专用源码高亮；井号词作为普通文本处理。
- 移除反链侧栏按钮、面板及专用索引；`[[双链]]` 的打开、创建和补全继续可用。
- 旧会话记住的标签或反链面板回退为文件面板；文档内容无需迁移。

## 🧪 测试与可靠性

- 本地默认测试从 1658 项增至 1801 项通过，0 项失败、36 项忽略；确定性慢用例另跑 20 项，全部通过。构建通过，无源码编译警告。
- 发布准备前共 69 笔提交，相对 v0.2.5 涉及 206 个文件，新增 10195 行、删除 5436 行。
- 增加真实 Markdown 语料、编码与外部修改、公式尾文、导出结构、成对标记逐字输入、设置交互及图片实际解码与原文件保护回归。
- 图片首帧闪字测试验证先失败、修复后通过，并确认恢复旧行为会再次触发断言失败。
- 本地验证运行于 macOS；macOS ARM64、macOS Intel、Windows x64 的构建、默认测试与确定性慢用例由原生 CI 执行。

## ⚠️ 已知限制

- 图片预览只读；首次打开仍需解码完整原图并上传纹理，未加入缩略图预解码或新的 dev 依赖优化配置。
- 字体列表来自系统已安装字体，字形表现取决于所选字体。
- macOS 安装包仍未签名和公证，在线安装需要系统授权；本地未执行真实系统安装。
- Cargo 提示既有依赖的未来兼容性问题，当前构建与测试通过。
