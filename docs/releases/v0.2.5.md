# v0.2.5

新增 GitHub Release 更新检查与在线安装，支持正式版、可选 beta 和启动检查开关。修复长文档首次滚动时滑块跳动、撤销重做时视口闪烁，以及搜索替换的焦点和确认交互。图片、代码块与表格统一以正文容器的 95% 排版，表格增加圆角、主题色表头和单元格悬停反馈。

## 📦 下载

| 平台 | 文件 | 说明 |
| :--- | :--- | :--- |
| macOS (Apple Silicon) | `velora-0.2.5-macos-arm64.pkg` | 双击安装 |

## ✨ 新增

**检查与安装更新**

- 启动时默认检查 GitHub 已发布正式版；设置可关闭启动检查，也可纳入预发布 beta。应用菜单和命令面板提供手动检查入口。
- 新版本在右下角显示通知，支持确认、取消和不再提醒该版本；手动检查仍可查看被忽略的版本。
- 确认后下载当前系统与架构的安装包，校验大小、格式与 SHA-256，处理未保存文档后安装并重启。Windows 保留已安装目录；macOS 安装到 `/Applications`，需要系统授权。
- 可取消下载；关闭下载窗口立即取消。多个窗口之间共享下载保护，关闭其它窗口的通知不会解除正在进行的下载。

**图片与表格**

- 图片默认 100% 缩放对应正文可视容器的 95% 宽度，最大不超过容器；右键提供 25%、50%、75%、100% 四档预设。
- 代码块与表格以同样的 95% 宽度居中。表格四周圆角，表头使用主题强调色与粗体，单元格悬停时显示淡色背景。
- 行内代码背景四边各增加 1px 留白。

## 🐛 修复

- 长文档第一次向下滚动时，代码块实测高度改变全文估高，导致滑块反向跳动；首次浏览和拖动滑块现在保持稳定，挂载区末行和占位间距也正确计入。
- 撤销、重做重新创建文档块后，首帧量高缓存失效使视口先跳动再返回；恢复时沿用原有布局和折叠现场。
- 折叠 H1/H2 后子标题仍显示；现在整段下级章节一起隐藏，直到同级或更高标题。
- 点击大纲跳转后，高亮被滚动跟随覆盖；保持点击目标，手动滚动后恢复跟随。
- 搜索输入支持鼠标定位、拖选和文字光标；默认高亮首个匹配，点击其它匹配后保留活动位置，替换单处后继续选中下一处。
- 支持替换为空；全部替换先展示查询、替换内容和全文匹配数量，再通过取消或确认执行。工作区范围隐藏单处替换按钮。
- 搜索跳转不再弹出选中文本的格式菜单；切换到文件树再返回搜索时保留查询与替换内容。
- 代码选区普通复制不再多出围栏与语言名；复制为 Markdown 按原围栏写法映射，保留字面反引号、中文与 emoji。
- Windows 文件菜单补齐手动检查更新入口，与偏好设置相邻。
- 侧栏右键菜单阻止底下文件行的悬停和点击穿透。
- Windows 并发测试的同名临时夹具不再依赖系统时钟，避免相邻测试覆盖文件。

## ⚠️ 语义变化

- 移除图片常驻缩放圆点和手动百分比输入；已保存的图片宽度属性继续可读。
- 文件树移除顶部过滤、排序栏与文件夹名称悬停提示；树排序仍可在偏好设置中选择。
- 在线更新只比较已发布版本，不使用仓库分支中的版本号。

## ⚠️ 破坏性变更

- 无文档格式或配置迁移要求。旧配置默认开启启动更新检查，并继续只检查正式版。

## 🧪 测试与可靠性

- 本地默认测试从 1610 项增至 1658 项通过，0 项失败、36 项忽略；构建和测试均无源码编译警告。确定性慢用例另跑 20 项，全部通过。
- 发布准备前共 19 笔提交，涉及 101 个文件，新增 5644 行、删除 1475 行。
- 增加首次通读、原生滑块拖动、撤销逐帧视口、搜索鼠标输入与替换、表格实际边界、更新版本筛选、下载校验及多窗口取消回归。
- 文件树、搜索、反链与标签列表按视口裁剪渲染，减少大侧栏每帧创建的元素。
- CI 在 macOS ARM64、macOS Intel、Windows x64 原生 runner 上分别执行构建、默认测试和确定性慢用例。

## ⚠️ 已知限制

- macOS 安装包仍未签名和公证；在线安装需要管理员授权。安装助手通过脚本语法及流程测试，本地未执行真实系统安装。
- 在线下载需要访问 GitHub，发布包必须提供 SHA-256 摘要；校验失败不会开始安装。
- v0.2.4 及更早版本尚无此次在线更新功能，首次升级到 v0.2.5 请下载对应安装包。
- Cargo 仍提示既有依赖的未来兼容性问题，当前构建与测试通过。
