# v0.2.9

本版把 v0.2.7 / v0.2.7..v0.2.8 两份评审报告里确认的问题修完：选区的归属判据、输入法组合的收尾、保存与另存为的落盘口径、跨格复制、导出与阅读视图的一致性，以及列表文档的解析工作量。同时补上 Windows 剪贴板的 HTML 味道、标签阅读位置与安装更新时的实例处理。

## ✨ 新增

- Windows 上从网页/其它编辑器复制的富文本改成按 HTML 味道读入：带样式的表格粘进来仍是表格，无表头表格不再落成纯文本。

## ⚡ 性能

- 松散列表（一项里很多子段）的解析：项内子块共用一份前瞻索引，扫描量随输入线性增长——同一夹具翻倍时每字节扫描量由 40.9 / 81.3 / 165.1 降到 3.5 上下。

## 🐛 修复

**命令与界面**

- 命令面板按平台真发得出的 Enter 执行选中项（此前只能用鼠标点）。
- 「打开最近」点了没反应的问题修掉；用户可见的提示不再被静默丢掉。
- 标题里的行内代码跟着标题字号放大。

**标签、阅读位置与工作区**

- 切走再切回的阅读位置按行锚点交还，首帧直接落位；切换视图模式也保留阅读位置，标签的编辑历史与块显示状态不再丢。
- 脏标签切回来时按盘上形状接回缓冲区：这一次落盘不再把 CRLF / UTF-16 / GB18030 洗成 UTF-8/LF。

**保存、另存为与关闭**

- 「保存并关闭」写当前缓冲区：确认框开着时继续打的字不再落在盘外，脏标记与恢复快照也不会被清掉。
- 另存为的目标正好是另一篇标签的文件时：带未保存修改的拒绝并说明，干净的目标按它记的盘上版本核一次再写。
- 自动保存与关闭前批量保存走同一套原子写判据（软链指向与文件权限保留）；一趟里多处失败只出一个框，带「重载 / 另存为」的冲突框不再被「保存失败」顶掉。
- 保存侧与标签侧用同一条路径键（Windows 上不再出现 `\\?\` 前缀的第二条键）。

**输入、选区与撤销**

- 表格里换格（回车 / Tab）先收跨格选区：下一键不再写回旧格子，字落在新格。
- 回车换行与敲字符同一口径：端点落在块首 / 块尾时整段跨块选区换成换行，不再留下前一块的半截文字。
- 链接标签里的输入法同字上屏也收尾撤销组：不再一次撤销退两步。
- 跨格复制按 (行, 列) 全量补位：`a | (空) | b` 复制出来是 `a		b`，空格子不再吃掉一列。

**Markdown、渲染与导出**

- 中文标点旁的删除线写回 `<del>…</del>`：界面划掉，导出 HTML / PDF 也划掉。
- 没配上对的行内 HTML 在导出里按字面显示，与阅读视图一致（不再在块尾自动补闭标签）。
- 缩进四格（或制表符）的 `$$…$$` 块导出成公式，与阅读视图一致。
- 公式定界改借应用侧那一处判据：`$$a\$$ 和 b$$` 整段是一个公式块，`a\\(b\\)` 不再凭空造出公式。
- 大纲 / 目录的围栏判据与正文同一处：四空格缩进的 ` ``` ` 不再让代码块里的 `#` 变成目录条目。
- 换正文字体（markdown）字体族即重测表格列宽，不再按旧字体钉住列宽、渲染 mid-word 折行。

**公式块**

- 公式块不再展示 `$$`（围栏归结构）；插入空公式块时留出正文那一空行。

**安装与更新**

- 安装包先关掉所有还跑着的 Velora，安装失败的原因不再只进日志；macOS 上安装前也收掉其他实例。
- 更新前先请其他实例自己关，不退就放弃这一趟，不再硬杀进程。
- 路径不再带 Windows 的 `\\?\` 前缀（「打开最近」整列都带着它）。

**配置**

- `[status_bar] custom_buttons` 接进运行时镜像：手配的状态栏按钮真正显示出来（此前解析了没人读）。

## ⚠️ 语义变化

- 没配上对的行内 HTML：导出按字面（此前按浏览器的自动闭合语义把后文染上样式）——以阅读视图显示的为准。
- 中文标点旁的删除线：写回 `<del>…</del>`（此前导出按字面）。
- 缩进四格的 `$$…$$` 块：导出按公式（此前按缩进代码块）。
- 手配的 `[status_bar] custom_buttons` 开始生效；偏好页保存不再抹掉配置里的那一段。

## 🧪 测试与可靠性

- 本地默认测试 2005 → 2069 项通过、0 项失败、39 项忽略；生成夹具后的确定性慢用例 23 项通过（72 秒）。生产构建通过，Velora 源码零警告。
- 本批 38 笔提交，涉及 113 个文件，新增 5976 行、删除 1136 行。
- 每条修复先写会红的测试再动实现：评审报告里的 13 条必修与 2 条候选逐条落到断言上；其中「表格列宽缓存缺正文字体族」复核为不成立（改正文族确实重测），留下守卫；「撤销组快照的每行前缀」是判据重复本身，收编后无独立红测。
- 本地验证运行于 macOS；macOS ARM64、macOS Intel、Windows x64 的构建、默认测试与确定性慢用例由原生 CI 执行。

## ⚠️ 已知限制

- 脚注定义**子块**的原文坐标映射仍退化（12 字节正文只映射 4 个偏移），这类块的撤销恢复选区会落到块首；根因在原文映射那一族，本版未动。
- 物理行多行粘贴到列表项正文时，续行不带容器缩进（`- 甲` 全选粘两行得到 `- 乙` 与块外的 `丙`）；本版未动这条插入文本的构造。
- 严格 CommonMark 无法表达的 CJK 强调仍用兼容写法（`<strong>` / `<em>` / `<del>`）：导出保留格式，原文相应字节会被改写（v0.2.8 起的承诺）。
- 墙钟预算闸门只在本地手动跑（CI 只跑确定性慢用例）；macOS 安装包仍未签名、未公证。
