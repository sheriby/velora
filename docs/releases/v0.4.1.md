# v0.4.1

本版本修复大文本文件打开和渲染时界面卡顿的问题。只有 Markdown 文件按 Markdown 解析，其余文本统一进入源码分块；超大源码块会跳过整块语法高亮，未知扩展名的大文件也能保持可编辑。

## 📦 下载

| 平台 | 文件 | 说明 |
| :--- | :--- | :--- |
| macOS (Apple Silicon) | `velora-0.4.1-macos-arm64.pkg` | 双击安装 |
| macOS (Intel) | `velora-0.4.1-macos-x64.pkg` | 双击安装 |
| Windows (x64) | `velora-0.4.1-windows-x64-setup.exe` | 双击安装 |

## 🐛 修复

- 非 Markdown 文本不再依赖扩展名白名单，未知扩展名的大文件也按源码文档打开并分块渲染。
- 超过源码预算的 JSON、JavaScript 等已知语言不再交给高亮器扫描整块内容，避免打开时阻塞界面。
- 图片和表格较多的长文档会把布局后的真实高度同步到滚动条，拖动位置不再逐步偏离正文。

## ⚠️ 破坏性变更

无。配置文件、会话文件与主题格式保持兼容。

- 本次发布包含 3 笔功能与文档提交，涉及 8 个源码/测试/文档文件。

## ⚠️ 已知限制

- 超大源码块为保证响应速度不显示语法高亮，仍可按纯文本编辑。
