# Velora v0.3.0-beta.2

这一版集中打磨 AI 助手与编辑操作：文档搜索改用 ripgrep 引擎并支持空格分隔的多词查询，工具调用失败与整轮卡住的问题得到修复，浮动窗可缩放、可收起，并新增默认收起的工具调用轨迹；表格改为单元格右键插入行列，文件树降低缩进并修复大树的逐帧开销。

## ✨ 新增

**AI 对话面板**

- 浮动窗右下角新增缩放手柄，拖动改变宽高；左上角位置不变，尺寸限制在窗口范围内，空对话也可调整，默认尺寸保持原样。
- 新增「工具调用 · N」轨迹，默认收起。展开后按时间顺序显示每次调用的状态（运行中 / 完成 / 失败）、工具名、参数与结果摘要；失败轮重试时轨迹随该轮一起回滚，恢复会话时上次未收尾的调用显示为失败。
- 浮动窗可收起到正文右下角的 Bot 图标方块，点击恢复原来的位置与输入内容；停靠侧栏不提供收起。
- 侧栏与浮窗的标题栏新增历史按钮，直接进入历史对话列表并恢复会话；更多菜单里的入口保留。

**表格**

- 单元格右键菜单新增：上方插入行、下方插入行、左侧插入列、右侧插入列、删除行、删除列。表头单元格不提供「上方插入行」，插入结果可用撤销恢复。
- 原表格右侧与底部悬停出现的加行加列按钮移除。

## ⚡ 性能

- AI 文档搜索改用编辑器同款的 ripgrep 引擎，磁盘文件按 CPU 核数并行扫描：50 个 1 MiB 文件冷启动 389→34ms，二次搜索 46→9ms（开发构建实测）。
- 不含 CR 的文本不再在换行规范化与内容版本计算时复制全文：1 MiB 文档首次 `read_document` 22→9.8ms，连续读 10 次 77→36ms（开发构建实测）。
- 文件树改为每帧只摊平整棵树一次，虚拟列表的总行数与可见区间复用同一份索引：10,002 个节点一帧 8.05→4.42ms（开发构建、无窗口、30 帧均值）。

## 🐛 修复

- AI 工具调用大量报 `unusable tool arguments`，连无参的 `list_documents({})` 也无法执行：Anthropic 兼容网关漏发 `content_block_stop` 或 index 时，已经完整流出的参数被留在未解析缓冲里，整轮被判定失败。现在可解析的累积参数会还原成工具调用继续执行，真正截断的参数重试一次并附带纠正提示；最终失败时错误包含工具名与原始参数片段。
- Chat Completions 网关在收到工具结果后挂住连接，界面一直显示「检索资料」：单次尝试 120 秒没有任何流事件时取消本次尝试并返回可重试的网络错误；工具结束后清空活动文案，回落到「生成中…」。
- 深色主题下 Mermaid 图表不可读：作者只写浅色填充（如 `fill:#fff8e1`）而未写文字颜色时，节点变成浅底浅字；预览画布固定在白色，浅色连线落在白底上几乎看不见。现在按填充的 WCAG 相对亮度自动补深色或浅色文字，预览画布在深色主题改用编辑器底色。
- 偏好设置保存成功后没有任何文字确认：现在在按钮左侧显示「已保存」，再次修改设置时消失。
- 深目录的文件名被缩进挤到截断：文件树每级缩进从 16px 减到 8px，与 VS Code 的层级步长一致。
- 并行工具调用时活动文案提前清空：现在保持到最后一个仍在运行的调用结束。

## ⚠️ 语义变化

- `search_documents` 的查询按任意空白拆成多个词，任一命中即返回（OR），大小写不敏感，正则元字符按字面匹配。此前整个查询被当作一个短语，多词查询几乎无法命中。
- 表格的悬停加行加列按钮移除，插入与删除集中到单元格右键菜单；右键菜单只能插入到相邻位置。
- 文件树每级缩进由 16px 改为 8px，深层目录的文件名获得更多宽度。

## ⚠️ 破坏性变更

无。会话文件新增带默认值的 `tool_calls` 字段，旧版会话仍可读取，旧版应用会忽略该字段。

## 🧪 测试与可靠性

- 本版 11 笔提交，50 个文件，+3937 / −741 行。
- `cargo build` 零警告；`cargo test --bin velora`：2661 通过、0 失败、54 忽略（v0.3.0-beta.1 为 2615 通过）。三个平台的构建与确定性慢用例由 CI 在推送 tag 后执行。
- 新增守卫：多词 OR 的跨文档命中、任意空白与大小写、元字符字面量与空白串拒绝；Anthropic 流式漏发 `content_block_stop`、缺 index、多个工具、双编码与重试上限；工具轨迹按 id 配对、失败轮回滚与恢复收口；浮窗缩放（有消息与空对话）、收起与恢复、历史入口；表格插入行列的模型、写回、撤销与右键菜单；文件树每帧一次遍历与 8px 缩进；换行规范化不影响内容版本。

## ⚠️ 已知限制

- 本版为预发布，用于收集这一轮 AI 与编辑操作的反馈。
- `search_documents` 只按空白拆词，不支持引号包裹的短语或布尔表达式。
- 工具调用轨迹从本版开始记录，旧会话恢复后不显示升级前的调用记录。
- Mermaid 只对十六进制与 `rgb()` 填充自动补文字颜色，命名色（如 `lightyellow`）不处理；作者显式声明的 `color` 保持优先。
- 文件树的逐帧摊平优化仅覆盖文件树，大纲页签仍按原路径逐帧遍历。
- Windows 专属代码（剪贴板 HTML 读取）本地无法编译验证，由 Windows x64 的 CI 任务把关。

## 📝 其他

- 依赖未变；AI 运行时修复全部在应用侧完成，未修改 yoagent。
- Mermaid SVG 缓存版本升至 `mermaid-svg-v4`，旧缓存自动失效，首次渲染会重建缓存。
- 架构文档同步：AI 搜索语义与并行扫描预算、浮动窗缩放与工具轨迹的持久化、文件树缩进与单次遍历规则。
