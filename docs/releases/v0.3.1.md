# Velora v0.3.1

本版是 v0.3.0 的补丁版本：新增默认关闭的 Vim 模式（Beta），修复复制的 Markdown 保真、AI 浮窗排版与 GBK/GB18030 文件打开，并补齐表格、公式与输入法相关的一批问题。

## 📦 下载

| 平台 | 文件 | 说明 |
| :--- | :--- | :--- |
| macOS (Apple Silicon) | `velora-0.3.1-macos-arm64.pkg` | 双击安装 |
| macOS (Intel) | `velora-0.3.1-macos-x64.pkg` | 双击安装 |
| Windows (x64) | `velora-0.3.1-windows-x64-setup.exe` | 双击安装 |

## ✨ 新增

- **Vim 模式（Beta，默认关闭）**：参考 Zed 的模态编辑，支持普通、插入、替换与字符/行/块状可视模式，操作符、文本对象、寄存器、宏、标记、搜索、`:` 命令行与点重复；`config.toml` 的 `[vim]` 段可开关、设置映射超时、同步系统剪贴板，并把 `jj` 一类序列映射为 Esc。
- **选中工具栏可关闭**：设置 → 通用新增开关，默认开启；关闭后选区不再浮出工具栏。
- **「复制为纯文本」**：正文右键菜单新增，复制去掉 Markdown 记号后的文字。
- 正文右键的 AI 入口改为二级列表，列出摘要、解释、翻译、润色、扩写五个快捷指令；`⌘J` 仍直接打开对话。

## 🐛 修复

- 默认复制改为交出 Markdown 源码，行级复制粘贴不再洗掉 `**`、反引号与标题记号，也不再多出空行；粘贴连续非空行仍是一段。
- AI 浮窗拖窄后正文按新宽度重排，宽表格不再把整条消息撑出面板。
- GBK/GB18030 文件可从工作区正常打开；编码无法无损写回时拒绝打开，原文件保持不动。
- 开启 Vim 后：普通模式不再向正文落字；表格单元格可编辑并正确撤销；行级跨块删除不再吞并后一块；`zt`/`zb` 真正对齐上下沿；映射前缀超时后按键仍然生效；行级复制粘贴按 Markdown 源码认块。
- 修复拼音预编辑与汉字之间的多余间距、公式预览高度塌陷导致的页面抖动，以及块状光标与模式标签的显示。

## ⚠️ 语义变化

- 默认复制改为 Markdown 源码；`⌘⇧C` 不再绑定，右键菜单的「复制为纯文本」提供去掉记号的那一份。
- 粘贴连续非空行按软换行合并为一段，不再逐行开块。
- 选中工具栏默认开启，可在设置中关闭；关闭后段落与 AI 下拉一起隐藏。
- Vim 模式默认关闭，开启后按键只作用于文档编辑区，应用快捷键与侧栏不受影响。

## ⚠️ 破坏性变更

无。配置文件与文件格式向后兼容；`⌘⇧C` 不再绑定，见上节。

## 🧪 测试与可靠性

- 自动测试由 2671 项增至 2865 项，全部通过；53 条慢用例与诊断探针默认跳过；生产构建零警告。
- 相比 v0.3.0 共 44 笔代码提交（不含发布准备），涉及 98 个文件，新增 12084 行、删除 688 行。

## ⚠️ 已知限制

- Vim（Beta）：块状可视的 `.` 重放、跨块 `gn`/`cgn` 未支持；自定义映射只收 1–8 个可打印 ASCII 字符，`<leader>` 固定为空格；`:` 命令不支持参数与模糊查找。
- 编码：无 BOM 的 UTF-16 不做猜测、拒绝打开；Big5/Shift-JIS 等恰好是合法 GB18030 的旧编码会按 GB18030 打开，暂无以指定编码重新打开的入口。
- 搜索：正则模式仍忽略 fuzzy；非法正则退化为字面搜索；模式不能跨行。
- AI 浮窗仍只能在主窗口内移动，暂不支持移出窗口。
