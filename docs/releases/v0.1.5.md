# v0.1.5

补丁版本，范围集中在两处：工作区搜索与文档内跳转的正确性，以及 YAML front matter 的呈现。搜索结果的完整性、行号口径、点击落位与滚动定位在本版一次性收口，跳转过程中触发进程异常终止的问题同时修复。

## ✨ 新增

- **YAML front matter 属性面板**：文档开头的 `---` 围栏对按字节保留，不再解析为分隔线与段落。阅读态将其内容渲染为属性面板——底色取主题的 `code_bg`，键名列对齐并以 accent 色标识，值为普通正文样式，列表值以逗号连接；围栏行与块标量指示符（`>`、`|`）不显示。该块与代码块同构，支持块内编辑。HTML、PDF 与预览导出将其转换为 GitHub 风格的键值表格，不交由 Markdown 渲染器处理。
- **搜索跳转诊断开关**：设置环境变量 `VELORA_SEARCH_JUMP_DEBUG=1` 后输出点击、重定位与滚动各环节的日志（`[SEARCHJUMP]` 前缀），用于定位「点击无响应」类问题。重定位失败不再静默，改为滚动至近似行并选中该行。

## 🐛 修复

搜索结果的完整性、行号与落位源自同一条链路上的两处文本不一致：扫描读取磁盘文件，跳转与高亮定位使用编辑器序列化文本，而序列化会重排表格并补全空行。

- **结果数量**：单文件命中数上限为硬编码的 3 条，超出部分不返回。改为全量收集，仅保留全局 200 条上限。
- **行号口径**：两种文本的行数不同，磁盘行号在序列化文本中失准。本版定盘为：搜索以磁盘文件为准，返回行号即磁盘行号（与 VS Code、Obsidian 一致）；点击落位以「同一文件内第 k 个含词行」作为对应关系，不依赖行号换算——规范化只改变行的位置、不增删内容行，该对应关系在任意偏移下成立。附带修正两处缺陷：`ordinal` 为 0 时实际选中第二个含词行；路径比较未做 `canonicalize`，在符号链接表示不一致时（macOS 的 `/var` 与 `/private/var`）整个跳转被静默跳过。
- **表格内命中无法跳转**：单元格实体不注册于文档块树且不能持有窗口焦点，跳转后焦点回落至首块，滚动目标被带向文档开头；表格位于未绘制区域时缺少布局边界，基于可见列表的估算遍历对单元格恒失败；表格运行时重建后，指向单元格的引用失效。滚动锚点统一解析为可滚动实体——单元格映射为宿主表格块（整表滚入视口，选区保留在单元格内），失效引用回退至可聚焦注册表，并在重建前识别、重建后迁移。
- **未浏览过的文档跳转无响应**：目标块位于未绘制区域时无布局边界，估算滚动与精确居中互相抵消，稳定帧耗尽后停留在中间位置（表现为「浏览一遍后正常，未浏览则不响应」）。现改为：距目标约一屏半以外时大步估算，接近后每帧以半屏单调逼近且不过冲；估算与逼近仅在程序化跳转时启用；跳转期间保持目标块位于渲染窗口内，使精确居中始终有可用坐标；稳定窗口按用途分级（跳转型 24 帧，初始可见性维持 6 帧）。
- **命中停在视口边缘**：居中结束条件原为帧数上限，布局仍在变化时标志先行失效，目标停留在贴近视口底边处。改为以偏差达标为条件（目标中心与视口中线偏差不大于 2px，实测 0.0px），帧数仅作 1.5 秒超时保护。文档首尾的命中有意贴顶或贴底，不保留半屏空白。
- **「上一个 / 下一个」在工作区范围下无响应**：入口函数对非当前文档范围直接返回，Enter 键与两个按钮均为空操作。统一为单一入口，工作区范围内按结果索引循环并支持环绕。
- **当前命中缺少视觉标识**：活动命中区间仅有写入、无渲染消费，在同屏多个命中之间循环时无反馈。新增主题变量 `search_active_highlight_bg`（六个内置主题、TOML 自定义主题缺省值与主题变量表同步），当前命中以深色显示、其余以浅色显示；高亮同步统一在跳转结束时触发，覆盖点击结果、Enter 循环与大纲锚点。
- **工作区命中无高亮、视口停留在文档顶部**：高亮同步限定于「当前文档」范围，且切换文档后未重新计算。取消范围限制，并在两条跳转路径末尾补充同步。
- **大纲与锚点跳转的累积漂移**：偏移基准取导入时的原始文本，而源码映射与搜索锚定序列化文本；相邻根块之间补入的空行使两者每一处相差 1 字节并随文档深度累积（表现为跳转后光标落在目标词中间）。统一为同一基准，且映射遍历不再假定根块之间恰有一个空行，改为按原文实际存在的空行数跳过。
- **跳转导致进程异常终止**：源码映射按推算位置切分文本，起始偏移落入多字节字符内部时，在非展开执行上下文中直接终止进程。改为映射锚点与序列化结果同源——单次序列化同时产出各非空根块的行区间，构造上不存在累积偏差；块内映射的越界字节一律对齐至字符边界。以 431 行中文文档做全量扫描验证：无错位、无越界。
- **深色主题下当前行高亮遮挡正文**：`current_line_bg` 原为不透明度 94% 的白色。改为由各主题的选区色派生（alpha `0x66`，Forest 为淡绿系），默认主题的缺省值降为 5% 白色；新增断言约束六个内置主题的该色不透明度不超过 0.45。
- 清理误提交至仓库的诊断临时文件。

## ⚠️ 破坏性变更

- 无。安装包、快捷键与配置格式均未变化。
- 语义说明：搜索结果行号为磁盘行号。文件存在未保存修改时，返回的行号可能与编辑器当前显示的行不一致；点击落位不受此影响。

## 📝 其他

- 测试 1083 通过 / 0 失败。本版回归用例均为端到端形式：真实工作区扫描后点击第 183 行命中（断言滚动量与选区位置）、30 行表格的全量命中并点击末位命中（目标位于未绘制区域）、表格内关键词命中跳转、含未保存修改的文件按 `ordinal` 跨过插入行跳转、「跳至深处 → 反向跳回首屏」双向断言、居中偏差不大于 2px。
- 移除一次性诊断输出及仅为打印而读取的临时变量（相关数值已包含在断言的失败信息中）；删除依赖本机另一仓库绝对路径的一次性用例，其覆盖场景已由三条常驻用例承担。
