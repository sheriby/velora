一次以「修掉报上来的问题」为主的补丁版：界面缩放终于真的生效，查找与搜索跳转不再丢焦点或落错位置，外部改文件会刷新文件树，配置写入与撤销更安全。

## ✨ 新特性

- 无。本次为修复与稳定性版本。

## 🐛 修复

- **界面缩放真正生效**：此前偏好设置「窗口 → 界面缩放」与 ⌘+/⌘−/⌘0 只缩放编辑器外壳，正文完全不动。现在正文、标题、代码块、行内代码与表格（含列宽换算）统一按缩放比例渲染，标题层级保持不变。
- **查找**：打字后立刻按回车就能跳到命中（不再被 120ms 去抖窗口吞掉）；跳转不再把焦点从查询框抢走（此前后续按键会当成正文输入）；命中位于折叠章节时自动展开；切换视图模式或收起侧边栏后高亮不再残留。
- **侧边栏贴边浮层**：在浮层里滚动滚轮不再带着正文一起滚；贴左边缘的触发区由 15px 放宽到 30px，更容易唤出。
- **工作区搜索**：文件有未保存修改时点击搜索结果，按内存文本重新定位命中（此前偏移错位，会跳到别处或文件末尾）。
- **外部文件变化**：新增、删除、修改都会刷新文件树（此前只处理修改）；只打开单个文件时也会监听所在目录；反链/标签面板同步更新；代码文件里的 `[[链接]]` 被外部改动后重新索引。
- **保存与冲突**：手动保存后继续打字不再误报「文件被外部修改」并停掉自动保存；自动保存冲突会指向真正发生变化的那个文件。
- **撤销**：文件历史恢复可以撤销；通过对话框插入表格也可以撤销。
- **Esc**：可关闭信息弹窗与窗口内菜单栏；关闭快速打开或命令面板后焦点回到正文。
- **命令面板**：支持输入法输入中文等非 ASCII 文本（此前打不进去），退格按字素删除。
- **配置更安全**：`session.json` 与 `config.toml` 改为原子写入，断电或崩溃不再留下半写文件导致设置静默回退默认。
- **搜索缓存**：加长度校验，同一秒内被改写的文件不再读到旧内容。

## ⚠️ 破坏性变更

- 无。

## 📝 其他

- **界面缩放的范围**：作用于文档排版（正文、标题、代码、表格）。侧边栏、状态栏、菜单等界面文字仍使用主题字号，不随缩放变化；全局 UI 缩放涉及固定行高与内边距的成批调整，留到后续版本。
- 本次改动源自一次覆盖 27 个缺陷与性能项的代码审查：已修 21 项（查找、搜索、文件监听、保存、撤销、输入法、配置安全、界面缩放等），其余 6 项为渲染层性能重构，需要基准与滚动回放用例守门，清单见 `docs/plans/2026-09-30-bug-audit-and-fix-plan.md` 第 4.1 节。
- 修复发布流水线把非安装包附件也挂上 Release 的问题，v0.1.4 的 Release 只含安装包。
