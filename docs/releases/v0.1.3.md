# v0.1.3

知识管理到位、超长文件不卡：新增反向链接 / 标签面板与 `[[` 自动补全，超长行（JSONL、日志）折叠渲染不再卡死，文件保存历史可回溯，GBK 旧笔记直接打开，外加一批编辑细节与 Windows 稳定性修复。

## ✨ 新特性

- **反向链接面板**：侧栏新增「反链」页，列出工作区内通过 `[[链接]]` 指向当前文档的笔记，点击打开；未保存的编辑即时反映在结果中。
- **标签面板**：侧栏新增「标签」页，按引用文件数聚合展示工作区 `#标签`，点击进入工作区搜索。
- **`[[` 自动补全**：输入 `[[` 弹出工作区文件名列表，继续输入过滤、↑↓ 选择、Enter 插入 `文件名]]`；围栏代码块与行内代码中的链接不会误触发索引。
- **超长行折叠**：源码/代码文档中超过 1024 字符的行折叠为单行（超出部分裁切显示），点击行号 ▸ 展开按宽换行——每行兆级的 JSONL、日志文件滚动编辑不再卡死。
- **文件本地历史**：每次保存自动留一个版本（每文件保留最近 20 条），菜单「文件 → 文件历史…」（⌘⌥H / Ctrl+Alt+H）浏览时间线，恢复为未保存修改（可继续编辑或撤销，不直接写盘）。
- **GBK/GB18030 自动识别**：非 UTF-8 的中文旧笔记（GBK 编码）可直接打开编辑，保存仍为 UTF-8；UTF-16 文件维持原有占位提示。
- **双击选词**：按 Unicode 词边界选中所在词——拉丁文整词、中文按字、空白标点各自成段。
- **表格表头居中**：表头默认居中，显式 `:---` / `:---:` / `---:` 对齐语法优先。
- **当前行高亮与括号匹配高亮**：光标所在行整行底色；光标附近的成对括号高亮（新增主题变量 `current_line_bg`、`matching_bracket_bg`）。
- **图片右键菜单**：在文件管理器中显示（macOS 访达 / Windows 资源管理器）、复制图片地址。
- **侧边栏自动隐藏**：收起后整条侧边栏（含活动栏）不再占位、正文满宽；指针贴窗口左缘停留唤出，滑入滑出带动画，扫过不误触。
- **模态对话框支持键盘**：Enter 触发默认按钮、Esc 取消，不再只能鼠标点击。
- **默认主题改为 Forest**。

## 🐛 修复

- 修复拖拽打开 `.jsonl` / `.log` / 无扩展名文件时被误当 Markdown 解析（与工作区打开行为不一致）。
- 修复贴边唤出的侧边栏浮层从窗口最顶端滑出、盖住标签栏与红绿灯的问题。
- 修复 Windows 原生文件对话框第二次打开卡十几秒（专用 STA 线程）。
- 修复 Windows 下拖动/缩放窗口后大小位置不记忆。
- 修复 KaTeX 字体未嵌入导致 Σ/∫ 等符号退化成小字形；行内公式改用行内排版。
- 修复打开文件对话框无法选中文件、按钮文案错误。
- 修复活动栏「大纲」按钮不支持再点一次收起侧边栏。
- 修复 Windows 汉堡菜单贴按钮下沿展开、间距与标题栏高度/主题解耦。
- 修复偏好设置「文件」「窗口」页超高内容无法滚动。
