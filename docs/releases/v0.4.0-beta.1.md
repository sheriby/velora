# Velora v0.4.0-beta.1

本版是 v0.3.3 之后的一次大版本，带来三击选段、Shift+↑/↓ 纵向扩选、Typora 式段落快捷键与状态栏侧栏开关；`==标记文本==` 的荧光底色在正文里真正可见。性能侧把撤销/重做、保存、粘贴、搜索替换与结构编辑的热路径从「整篇代价」改成「只动受影响的一段」；修复覆盖 Markdown 往返保真、表格、源码模式、Vim、公式与更新流程。因为是预发布，配置与文件格式仍按 v0.3.3 向后兼容，欢迎在 Issues 反馈问题。

## ✨ 新增

**选择与输入**

- 三击选中整块（段落/标题/列表项），双击仍是选词。
- Shift+↑/↓ 纵向扩选：块内按视觉行扩，越过块边界时选区延伸到相邻块，锚点留在原块；已有块内选区再跨块扩选不再丢掉已选内容。
- 段落族快捷键对齐 Typora：标题 ⌘1-6（⌃1-6）、正文 ⌘0（⌃0）、引用 ⌘⌥Q（⌃⇧Q）、无序列表 ⌘⌥U（⌃⇧]）、有序列表 ⌘⌥O（⌃⇧[）、代码块 ⌘⌥C（⌃⇧K）、表格 ⌘⌥T（⌃T）、数学块 ⌘⌥B（⌃⇧M）。切标签改为 ⌘⌥1-9（⌃⌥1-9），缩放重置改为 ⌘⌥0（⌃⌥0）。

**界面入口**

- 状态栏左端新增左侧栏开关，右端新增 AI 侧栏开关；AI 功能关闭时 AI 入口不渲染。
- 阅读模式下命令面板不再列出只写缓冲区的命令（格式、格式化文档、粘贴为纯文本）。
- 图片预览放大后可拖拽平移，按缩放后的图片与视口双向钳制。

**粘贴**

- 剪贴板 HTML 超过 2 MiB 时按纯文本落笔，并给出应用内提示。

## ⚡ 性能

- 撤销/重做按编辑区间区域重投影：201 根块的文档一次撤销只重投影 2 根以内（整篇重建路径为 201 根）。
- 手动保存、关闭多标签、外部变更重载、粘贴图片、工作区全部替换、HTML 转换都移到后台执行；主线程只做身份校对与提交。
- 结构编辑（插入/合并/删除/缩进/提级/降级/换种类等）改为以受影响根块为锚点重排快照后缀：40 段文档一次文末回车同步访问块数从 42 降到 4 以内。
- 表格列宽按列指纹复用，编辑一格只重测变化列；跨格选区只扫覆盖到的行列（30×8 表选两格 248→10 次格子读），拖动落点按行二分（22→6 次行几何读），选区端点移动只重铺两端（1010→10 次）。
- 懒导入文档在前段粘贴或回车不再整段物化未建尾部，尾部继续后台续建。
- 未闭合定界符的闭合预扫改线性：1200 字节样例预扫步数 160000→约 1200。
- 词起点表、源码行号槽、公式草稿布局、命令面板条目、右键菜单几何、窗内菜单派生量、渲染主题都按代数缓存，静止帧不再重复构建；选中工具栏与右键菜单改取文案表 Arc。

## 🐛 修复

**Markdown 与导出一致性**

- `==标记文本==` 在普通段落里终于有底色：此前底色只写在文本 run 上而绘制层不消费它；现在按 span 生成逐行底色四边形，明暗主题都用荧光黄，当前行高亮不会盖住它。
- 大量往返保真修复：引用懒续行与嵌套引用、引用/标注多行子块的逐行记号、Setext 标题、分隔线与空引用的原文写法、根级列表项的缩进与记号后空白、有序项分隔符后的空白、引用式链接的 full/collapsed/shortcut 写法、强调的 rule of 3、链接的三种标题定界符与空目标、未闭合反引号不再吞掉后续结构行。
- 解析/序列化保真：链接标签与强调记号不再互相吞并，title 转义可逆，多字节偏移映射收敛到字符边界；`<br/>` 等 HTML 写法按文档口径归一。
- 行内 HTML 递归深度设 64 层上限，深嵌套粘贴不再栈溢出；位图 `data:image/` 放行，SVG data URI 继续拒绝，协议相对图片按 https 处理。
- 导出保存对话框对外来扩展名追加目标扩展名（`notes.txt` → `notes.txt.html`），不再用错程序打开；导出 HTML 的注释块与 `mark` 底色恢复各自 token。

**编辑与写作**

- 代码块里 Tab/Shift+Tab 按行缩进/反缩进，不再用四个空格替换整个选区。
- 块尾 Delete 合并下一块，遇到表格按整块删除；源码分块文档 Cmd+A 全选整篇。
- Home/End 对齐光标所在视觉行，软换行后不再跨行。
- 混合可视路径补上斜体、删除线、链接与脚注下划线，聚焦前后不再跳变；长 CJK 段按字素折行，行内公式不再被整体挤到下一行。
- 有序列表项不再提供「任务列表」转换，避免静默把 `1.` 改成 `- `。
- 引用内粘贴与文档末尾补尾段落按区间写回，不再整篇重投影洗掉无关块的原文写法。
- 行内格式与清除格式不再触发快捷语法换种类；`__粗体__` 关一次再开一次仍保持 `__`，混合选区一次加粗不再出现两种记号。
- 空段落失焦后作废上一帧几何，点击不会再落进看不见的空块；坏编辑区间钳位到字符边界，不再崩溃。
- 未命名且无工作区的文档粘贴图片改为明确拒绝并提示，不再写进进程当前目录。
- 插入图片选了不支持的文件时给出应用内提示；粘贴图片的目标路径含空格时改用尖括号目的地。

**表格**

- 删除末列保留收尾管道；行尾多余空格不再让列级操作失效；从菜单插入表格只改写锚点区间。
- ragged 表的水平/垂直移动按实际格数定位，越过表尾交给相邻块。
- 表头列轴激活条不再盖住表头文字上沿；点表格块自身的 padding 区把焦点送进表格；行选择带移进表格内部，祖先裁切时不再消失。
- 单元格图片加载失败统一显示 alt；表格跨格替换只重解析表格根块。

**源码模式**

- `<!-->` 与 `<!--->` 按单行空注释收尾，不再把后文涂成注释色；引用块里的围栏代码按代码色着色。
- Setext 标题跨 512 行分块接缝时，下划线行仍出标题色；大 Markdown 源码回退与代码文档同走分块续建。

**搜索与双链**

- 20 MB 以上的文件仍读正文搜索，与「全部替换」同口径；文档范围结果计数读完整命中表，不再只报列表投影的 200 条。
- 搜索结果列表 ↑/↓ 同步活动命中，Enter 跳到高亮那一行；全部替换的计数复用搜索缓存，写盘挪到后台。
- `[[目录/文件名]]` 按相对路径打开；非法目标与无落点给出可见提示；补全空结果时 Enter 插入换行，候选先排序再截断，浮层按真实高度贴边。

**公式、图表与更新**

- 公式补全空结果不再留空面板；预览 120ms 防抖并后台渲染；关闭前比对快照，动过草稿才弹确认；解析不出分段的公式块应用时不再嵌套定界符；弹窗开着切主题预览跟着重渲。
- Mermaid 预览的 Esc 与主题重渲失败都走正式关闭并交还焦点；超大图显示按栅格预算等比缩小，文字不再发虚。
- 更新安装启动失败时保留待安装计划以便重试，也能重新下载；下载活动标志由 RAII 守卫复位，关闭窗口后不再永久卡在「下载中」；下载刻度只在进度变化时重绘。

**Vim**

- 标记与跳转表随块内编辑平移，结构编辑后 `gv`/`'<`/`'>` 仍能重定位。
- H/M/L 以视口内可见块为基准，不再等于 gg/G/全文中间。
- 行级可视的 J/gJ 按选区并段；R 模式退格按当前字符宽度还原；块状可视的 r 按矩形逐行替换。
- 显式编号寄存器写入与读取落到同一处；行级寄存器替换字符选区时前缀保持在上。
- 冒号命令补错误回显（E492/E486/E488），`:s` 拒绝不支持的标志与 `~`；`.` 重放加 256 步护栏，含不可重放键的插入会话不再污染 `.`；按键序列护栏放宽到 16 键。

**其他**

- 删除确认的「确认删除」不再作为回车默认项，Enter 落在「取消」。
- 右键菜单与表格插入对话框补齐焦点陷阱与键盘操作（Tab/Enter/Esc）；⌘P 与 ⇧⌘P 两个全局浮层互相关闭。
- 大纲在标题上方增删行后迁移展开与选中状态；视口 resize 不再取消未交还的阅读位置；焦点岛高度冻结，滚动条不再抖动。
- 偏好 setter 补上带锁读改写，配置写入不再互相回滚；所有配置原子写在 rename 后同步父目录。
- 混合可视块里的双链与普通链接同口径，需 Cmd/Ctrl+点击才打开。

## ⚠️ 语义变化

- 快捷键让位：⌘1-9 由切标签改为标题级别，切标签改为 ⌘⌥1-9；⌘0 由缩放重置改为正文，缩放重置改为 ⌘⌥0。
- 删除确认的回车默认项改为「取消」。
- 有序列表项不再提供「任务列表」转换（菜单置灰、动作拒绝），避免丢序号族。
- 导出时非目标扩展名会追加而不是替换：`notes.txt` 导出 HTML 落成 `notes.txt.html`。
- 剪贴板同时含文字与图片时优先粘贴文字；混合可视块的双链需要修饰键才能打开。
- 未命名且无工作区的文档不再允许粘贴图片（会明确提示先保存文档或打开工作区）。
- 源码分块文档的 Cmd+A 选中整篇，与渲染视图口径一致。

## ⚠️ 破坏性变更

无。配置文件、会话文件与主题格式向后兼容；外置主题可选新增 `mark_bg`，缺省时回退暗色荧光值。

- 相比 v0.3.3 共 238 笔提交、211 个文件，新增 22825 行、删除 3038 行。

- CI 新增 Feature combos job，锁定 core-only / config-only / official-only 三种组合持续可编译；Windows 测试目录清理改为重试，不再因杀毒占用假红。

## ⚠️ 已知限制

- 跨 512 行分块接缝的围栏不做语言内状态续析，引用内的围栏为整段代码色的保守版；Setext 标题跨接缝时上一块的正文档位无法回溯着色。
- 命令面板的只读过滤只覆盖「只读视图」这一维，不覆盖其它不可编辑场景。
- 脚注/标注等组行内部的成员间隙点击仍是死区（行间缝隙已覆盖）。
- Windows 没有目录 sync 通道，rename 后同步父目录只在 unix 生效。
- 以下评审条目复核后按「行为正确」保留，只补契约用例：块交界零宽命中的归块口径、选区端点随干净偏移单调、跨格撤销恢复格内选区、分屏共享变更队列有界。
