# v0.1.3-beta.2

本次测试版新增工作区反链与标签浏览。

## 📦 下载

| 平台 | 文件 | 说明 |
| :--- | :--- | :--- |
| macOS (Apple Silicon) | `velora-0.1.3-beta.2-macos-arm64.pkg` | 双击安装 |
| macOS (Intel) | `velora-0.1.3-beta.2-macos-x64.pkg` | 双击安装 |
| Windows (x64) | `velora-0.1.3-beta.2-windows-x64-setup.exe` | 双击安装 |

## ✨ 新特性

- **反链面板**：查看哪些笔记通过 `[[链接]]` 指向当前文档，并可点击打开；未保存的编辑也会反映在结果中。
- **标签面板**：按引用文件数展示工作区内的 `#标签`，点击标签可进入工作区搜索。
- **索引更新**：工作区文件树加载后建立链接与标签索引，文件变化时自动更新；围栏代码块和行内代码中的链接、标签不会计入。
