# Velora v0.3.0

新增 AI 文档助手：支持针对选区提问与改写，改写结果以待确认的修改标注在原文位置，确认后才写入文件，写入后仍可撤销。界面组件统一迁移至 GPUI Kit 标准控件，键盘操作与焦点顺序一致；同时新增网络代理配置与表格行列的右键操作。

## ✨ 新增

**AI 文档助手**

- 支持选中文字提问，或要求助手改写选区内容。
- 改写结果以待确认的修改标注在原文位置，确认后才写入文件；确认后的修改可正常撤销。
- 三种打开方式：`⌘J`／`Ctrl+J`、选区工具栏的「AI」、正文右键。
- 对话窗支持拖动、缩放与收起，也可切换为右侧侧栏，输入与结果保持不变。
- 内置摘要、解释、翻译、润色、扩写五个快捷指令，完成后可继续追问。
- 助手自行检索工作区：列目录、按文件名查找、搜索文本、读取标题；可读取范围由 Markdown 扩展到代码与配置文件。
- 通过 `@文件`、`@目录` 指定参考资料，或在偏好设置中排除文件。
- 对话中显示每次工具调用的参数与结果，以及模型的思考过程，默认收起。
- 阅读类任务不注册修改工具；限定选区的任务只能修改选区内的文字。
- 支持自备模型（DeepSeek、OpenAI、Anthropic、Ollama 及自定义服务）、自定义指令与 Skills。

**界面与操作**

- 标题栏、标签、侧栏、菜单、命令面板、偏好设置与对话框统一为标准控件，均支持键盘操作。
- 表格单元格支持右键插入与删除行、列。
- 新增网络代理设置，AI 请求、更新下载与远程图片均经由该代理。
- 偏好设置窗口在窄窗口与大字号下改为上下排布，保存成功后显示「已保存」。

## ⚡ 性能

- 文档搜索改用编辑器的 ripgrep 引擎并并行扫描磁盘：50 个 1 MiB 文件首次搜索 389ms 降至 34ms。
- 读取文档不再为规整换行复制整篇内容：1 MiB 文件首次读取 22ms 降至 9.8ms。
- 文件树每帧仅整理一次：10,002 个节点单帧 8.05ms 降至 4.42ms。

## 🐛 修复

- 模型服务漏发结束事件导致全部工具调用报参数错误，以及界面长时间停留在「检索资料」。
- AI 对话文本无法用鼠标选中与复制。
- 对话窗内打开历史列表时切换为贴边的宽面板。
- 深色主题下 Mermaid 浅色填充节点的文字对比度不足。
- 文件树每级缩进由 16px 减至 8px，深层目录的文件名不再被截断。
- Windows 路径携带 `\\?\` 前缀导致文件无法打开，以及更新提示排版异常。
- 全文查找改为从当前结果继续；修复输入法组词过程中的选区、撤销与光标位置问题。
- 配置文件并发写入互相覆盖；会话保存的耗时移出主线程。

## ⚠️ 语义变化

- AI 功能默认关闭，需在偏好设置 → AI 中开启并配置模型。
- 文本搜索按整串内容匹配，不再将空格分隔的词作为多个条件；查询多个主题需分别发起。
- 助手读写文件统一使用工作区内的相对路径，不再向模型提供绝对路径。
- 表格的插入与删除行列改由单元格右键菜单提供；五个快捷指令由正文右键移至选区工具栏。

## ⚠️ 破坏性变更

无。新增配置文件 `ai.json` 与按工作区隔离的会话目录，旧版本忽略这些文件，升级无需迁移。

## 🧪 测试与可靠性

- 自动测试由 2320 项增至 2671 项，全部通过；生产构建零警告。
- 三种模型协议下的工具调用过程均以本地模拟服务验证，CI 无需真实 API Key。
- 相比 v0.2.11 共 144 笔代码提交（不含发布准备），涉及 415 个文件，新增 54084 行、删除 95118 行。

## ⚠️ 已知限制

- 需自备模型服务与密钥；不执行 Skills 中的脚本，不接入外部工具服务。
- `.env`、`*.json` 等配置文件在可读范围内，保密条目需在偏好设置中排除。
- 对话窗仅能在主窗口内移动，暂不支持移出窗口；独立窗口支持列入后续版本。
