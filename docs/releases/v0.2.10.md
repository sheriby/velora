# Velora v0.2.10

本版改善 Mermaid 图表的原生渲染与查看体验，加入可缩放、可拖动的图表预览，并整理欢迎页和跨平台菜单。长文档编辑减少重复扫描与重建，同时修复输入法、表格选择、公式光标、剪贴板与导出的多项问题；H2 默认改为左对齐。

| 平台 | 文件 | 说明 |

## ✨ 新增

**Mermaid 图表预览**

- 点击正文中的图表进入应用内预览，支持适应窗口、原尺寸查看、缩放、拖动和 Esc 关闭。
- 预览使用底部悬浮工具条与独立关闭按钮，图表源码编辑入口继续保留。

**欢迎页与菜单**

- 最近打开列表增加路径提示和单条移除按钮；移除只清除记录，不删除实际文件夹。
- 最近记录采用紧凑单行布局，用户目录以 `~` 缩写，悬停查看完整路径。

## 🐛 修复

**图表与界面**

- 替换 Mermaid 渲染引擎，避免流程图回环触发布局断言后退出应用；调整中文字体回退和 SVG 缓存，改善图表显示。
- 正文图表适应列宽，较大图表通过独立预览查看；修复显示缓存尺寸与并发写入问题。
- 欢迎页统一使用「打开文件」，移除宣传语并补齐图标；文件夹通过专用菜单打开。
- macOS「关于」恢复正常显示，帮助菜单移除 CLI 安装与卸载入口。
- Windows「偏好设置」「检查更新」提升为一级菜单；「打开文件」「打开文件夹」「打开最近」连续排列。
- H2 默认左对齐，H1 的默认居中与表格对齐规则保持不变。

**长文档编辑**

- 自动保存只同步内容，不再重复采集整篇阅读位置；换标签时仍保留阅读位置。
- 打字时减少整篇可见块列表克隆，大纲、状态栏与文件悬停提示减少每帧扫描和磁盘访问。
- 行号与字节位置查询使用文本块索引，根块区间重挂改为查表，整篇重建不再重复刷新引用注册表。
- 普通链接段落的编辑不再触发整篇引用注册表重建；图表重绘优先复用进程内缓存。
- 引用扫描遇到不可信的源码区间时安全回退，避免切片导致崩溃。

**输入、选择与导出**

- 输入法选词期间，命令面板和快速打开不再把回车误当成执行命令。
- 表格反向拖动时，复制内容与高亮单元格保持一致。
- 缩进公式块的光标落点不再偏移；导出保留公式块后的正文及未配对的闭合标签。
- 自定义状态栏按钮正常执行所配置的命令。
- Windows 剪贴板读取失败时安全回退；过大的 HTML 内容改用纯文本，避免卡顿与崩溃。
- macOS 更新安装先请求其他实例正常关闭，无法关闭时中止本次安装。

## ⚠️ 语义变化

- H2 从默认居中改为默认左对齐，仅影响显示，不改写 Markdown 内容。
- Mermaid 图表布局与此前版本有所不同，缓存会重新生成。
- Windows 剪贴板的 HTML 内容超过 2 MiB 或不是有效 UTF-8 时，粘贴退回纯文本。

## ⚠️ 破坏性变更

无。已有 Markdown 文档不需要迁移。

- 默认测试通过数由 v0.2.9 的 2069 增至 2110；0 项失败、42 项忽略；生产构建通过。
- 生成性能夹具后，确定性慢用例：23 项通过；墙钟性能预算不纳入 CI。
- 相比 v0.2.9，本批共 47 笔提交，涉及 105 个文件，新增 6183 行、删除 647 行。
- 增加缓冲区索引差分、源码区间、重复扫描、图表缓存与预览、欢迎页和菜单等回归覆盖；缓存读盘探针按线程隔离，避免并行测试互相污染。

## ⚠️ 已知限制

- 复杂 Mermaid 块图仍可能出现标题重叠或与 Mermaid.js 不同的布局；Windows 字体与图表视觉效果仍需实机验收。
- 超大文档的撤销仍需整篇重建，可能明显慢于普通输入。
- macOS 安装包未签名、未公证。
