# Velora v0.2.11

本版新增编辑器分屏、未命名草稿与窗口级只读阅读模式，扩展文件历史为自动快照、预览、对比和可撤销恢复，并支持基准与增量存储。块公式加入实时预览、花括号配对与自动编号，图片和 Mermaid 可进一步缩放；文件树支持拖放移动与外部文件导入，浏览大型工作区时按需加载并复用缓存。

## ✨ 新增

**编辑器分组与分屏**

- 支持左右、上下分屏及嵌套布局，拖动分隔条调整比例，各组独立保留标签、滚动、光标和视图模式。
- 拖动标签或文件树中的文件到正文边缘创建分屏，拖到中央在目标组打开；支持移动与复制视图，未打开的文件也能直接拖入分屏。
- 同一文件的多个视图共享内容与撤销历史；保存、外部修改冲突和关闭确认统一处理，分屏布局随会话恢复。
- 默认通过 `⌘\` / `Ctrl+\` 向右分屏，也可使用标签右键菜单和命令面板。

**未命名文档与草稿恢复**

- `⌘N` / `Ctrl+N` 在当前工作区的活动组创建独立 `Untitled` 标签，可同时保留多份草稿并参与分屏。
- 草稿自动写入恢复快照，重启后恢复标签与内容；首次保存选择路径后，原标签就地转为正式文件。
- 关闭、退出和拖入其他文件时保留未保存草稿；取消保存会保留正文与窗口。

**文件历史：自动快照、预览对比与恢复**

- 自动保存也能形成历史版本；默认自动快照最少间隔 5 分钟、每文件最多 30 条、保留 7 天，三项均可在偏好设置调整。手动保存可记录检查点，同内容去重。
- 增加只读历史预览、与当前正文的按行对比及差异跳转。所有版本均以当前内容为基准，包含未保存修改；标题显示文件名，时间按系统本地时区显示，字体沿用代码字体设置。
- 恢复需要确认，恢复前备份当前内容；恢复可撤销，保留现有撤销链及当前文件的编码和换行方式。
- 首次保存完整基准，后续小改动保存增量；增量不划算或链长达到上限时保存全文，清理旧版本前补齐仍被依赖的基准。已保存的历史可独立重建，不以当前工作区文件内容作为存储基准。
- 新增历史仅适用于实际保存字节不超过 1 MiB 的 `.md` / `.markdown` 文件；更大或非 Markdown 文件仍可正常保存。既有完整快照继续可读。

**只读阅读与稳定的标记显示**

- 新增默认关闭的阅读模式，整个窗口的标签和分屏共用只读状态，其他窗口独立。保留滚动、选中、复制、查找、折叠、链接及预览，阻止正文输入、格式、替换、撤销重做和历史恢复。
- 点击状态栏眼睛图标，或通过视图菜单、命令面板、正文菜单及 `⌘⇧R` / `Ctrl+Shift+R` 切换；阅读与源码按钮在状态栏右侧集中排列。
- 偏好设置新增默认关闭的“隐藏 Markdown 标记”：开启后，聚焦已渲染的粗斜体、行内代码、链接等内容时继续隐藏标记，减少行宽变化与换行跳变；Markdown 原文不变，源码视图继续显示原始语法。

**公式编辑与图像缩放**

- 编辑块公式时在源码上方显示实时预览；输入未完成的语法时保留最近一次成功结果，预览区域保持稳定。
- 未识别的 LaTeX 命令原位显示为红色文字，其余公式继续排版；输入花括号自动成对，支持跳过已有闭括号和成对删除。
- 块公式按文档顺序显示 `(1)`、`(2)` 等编号，覆盖引用与分批加载，增删及撤销后同步更新；编号不写入 Markdown。
- 独立图片预览支持鼠标滚轮和触控板缩放，范围为初始适应尺寸的 10%～800%；Mermaid 预览通过按钮、滚轮及快捷键可放大至原尺寸的 200%。缩放不修改原文件。

**文件树拖放与按需加载**

- 文件树内支持拖放移动文件与目录，外部文件或目录拖入树中时复制；目录行、文件行和空白处分别使用目录自身、父目录和工作区根作为落点。
- 拒绝覆盖同名目标和把目录移入自身；移动后同步打开的标签、分屏和图片路径，保留未保存内容与符号链接。
- 外部文件拖入编辑器时逐个打开为固定标签，图片打开独立预览；未命名正文保留在原标签。
- 首次只读取当前层，子目录展开时再加载；搜索、快速打开与双链按需建立共享文件名单。当前会话内复用同根缓存，文件变化按路径增量更新。

## 🐛 修复

**自动更新与窗口**

- 从原生菜单检查更新不再因窗口重入借用而崩溃；下载后的安装交接统一经过保存与退出流程，最后一个窗口关闭时也能继续交接。
- 更新前检查仍在运行的其他工作区实例，提示保存并关闭后重试；安装准备、校验或启动失败时显示应用内错误并允许重试。
- 标签可拖到最后一个标签之后；macOS 拖动标签不再同时拖动窗口。标题栏空白与分组间空白可拖窗，标签占满后仍保留拖窗区域。
- 单个编辑器组不再显示分组色线；菜单按实际字体、字号与快捷键测量尺寸，减少截断与子菜单重叠。

**大纲、文件树与编辑显示**

- 长大纲随正文滚动将当前标题带入可见区，多级折叠入口恢复可用；大量侧栏条目滚动时不再出现空白或越界。
- 文件、目录与空白处使用各自适用的右键菜单；新建名称输入位于子目录之后、第一个直属文件之前。空白名称失焦时取消新建，显式按 Enter 仍执行校验。
- 打开右键菜单后可连续右键切换目标；剪贴板没有有效文件或图片时隐藏粘贴入口，避免粘贴过期内容。
- 无法读取的目录不再每帧重试，走盘跳过文件时给出提示；同根重开与普通文件修改不再反复清空缓存或重排目录。
- 长行展开箭头不再与行号重叠，悬停显示手形；引用中的公式保留竖线，空引用容器不再多占一行。
- 工作区内本地图片被外部修改后，正文和独立预览可同步刷新，无需重新打开文档。
- 修复链接目标中的 `$$` 被误当作公式闭合而导致导出整段内容消失；减少普通表格输入时重复重建整篇引用注册表，并补齐引用定义变化的刷新。

## ⚠️ 语义变化

- `⌘N` / `Ctrl+N` 改为在当前工作区新建未命名标签；旧 `new_window` 自定义键位映射到 `new_document`。
- `⌘\` / `Ctrl+\` 用于向右分屏，“清除格式”移至 `⌘⌥\` / `Ctrl+Alt+\`。分屏入口集中于标签菜单、命令面板、快捷键及拖放。
- 侧栏搜索默认范围改为当前文档，需要全局搜索时切换到所有文件。
- 将外部图片文件拖入编辑器时打开预览；插入正文可继续使用粘贴或“插入图片”。拖入文件树则导入到目标目录。
- 文件树缓存仅在当前应用会话内复用，不跨应用重启持久化。

## ⚠️ 破坏性变更

Markdown 文档本身不需要迁移，既有完整历史快照仍可读取。新版文件历史开始写入增量格式，旧版不能完整读取这些新增量历史；如需回退版本并保留对它们的访问，应先在新版恢复或另存需要的内容。
