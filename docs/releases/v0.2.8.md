# v0.2.8

本版修复编辑、选择、撤销、渲染与保存之间的核心协议问题。富文本编辑回到正确的原文位置，跨块与跨格选择在输入、复制和撤销中保持一致；长文档滚动不再使用屏外旧几何，主题变化与输入法组合也能正确更新排版。保存和标签切换进一步保护原始编码、外部修改与私有文件权限。

## ✨ 新增

本版专注核心修复与性能，没有新增功能。

## ⚡ 性能

- 局部选区扩展、回缩和清除不再访问全文：同组操作在 100/1000 块中的访问数由 505/5005 限制到 16 次以内。
- 缓存行高与滚动权重前缀，稳定帧通过索引定位窗口：1000 段文档的五帧重复行高访问由 10190 次降为 0 次。
- 段落维护增量代码跨度状态，围栏闭合前瞻在分批加载间共享；空行边界和未闭合围栏不再反复扫描全文前后缀，新增工作量断言守住线性增长。
- 连续输入时局部合并小文本分块，避免碎片数随编辑次数增长；渐进加载在批次之间实际让出前台。

## 🐛 修复

**编辑、输入与撤销**

- HTML 行内样式、代码跨度、脚注及表格中的编辑按真实原文坐标定位，多行粘贴不再插进标签或遗漏被选中的文字。
- 跨块、跨源码分块与跨格选择统一用于输入、复制、删除及视图切换；空锚点和渐进加载的新格子也正确接收输入。
- 撤销捕获修改前的选区和方向；输入法同文本提交与取消也结束组合状态，后续输入、历史和保存不再串组。
- 跨格输入保留相对选区与组合范围，竖线和换行遵循表格源码规则；公式格起拖后拖回同格仍保持整格选择。
- 标题、引用等块降级或切换类型后，左右相邻边界正确写回，继续输入和撤销与重新打开的解析结果一致。

**渲染与滚动**

- 长文档命中测试只读取当前有效挂载集合，分组真实成员与焦点岛都参与几何和行高回收，屏外表格旧坐标不再影响选区。
- 选择高亮按当前显示投影派生；公式与混合视觉呈现不再残留旧文字布局。
- 样式、组合标记、表格字体与完整主题度量纳入缓存失效条件，文字不变时也能正确更新粗斜体、下划线、列宽和行高。
- 搜索跳转公式与图表使用实际原子边界，查询框保留焦点；所有等待布局的重试都有终止预算。
- 查询框持有焦点、行高重新测量时，冷启动补帧仍能补齐后文，不再依赖正文光标闪烁。

**文档与保存**

- 切换或替换渐进加载文档后，旧任务和旧尾部不能进入新文档。
- 脏标签重新激活同时恢复原文件编码、BOM 和行尾。
- 手动、自动与保存关闭共用原子提交协议，保留已有权限与软链指向；过期请求不能覆盖外部版本或新文档状态。
- 首次异步登记磁盘版本前，手动保存也检查打开时的原文基线，避免覆盖刚发生的外部修改。

**Markdown 与导出**

- 中文标点旁的强调在编辑器中正确配对，手动加粗、斜体在严格 CommonMark 无法表达时使用兼容写法，导出保留格式。
- 行内 HTML 净化保留安全标签的开闭配对，不再提前闭合并把正文移到样式外；危险属性与地址仍经过既有清洗规则。

## 🧪 测试与可靠性

- 本地默认测试 1918 → 2005 项通过、0 项失败、39 项忽略；生成夹具后的确定性慢用例 23 项、逐条运行的墙钟预算与手动探针 16 项全部通过。生产构建通过，Velora 源码零警告。
- 发布准备前共 42 笔提交，相对 v0.2.7 涉及 85 个文件，新增 6413 行、删除 771 行。
- 核心修复按功能分别提交，以失败回归确认缺陷后再实现；操作验收覆盖实际输入、字节、复制、撤销、保存和视口几何。
- 本地验证运行于 macOS；macOS ARM64、macOS Intel、Windows x64 的构建、默认测试与确定性慢用例由原生 CI 执行。

## ⚠️ 已知限制

- 直接书写的部分 CJK 强调方言在编辑器中成形，但严格 CommonMark 导出仍可能显示为字面；本版修复的是手动格式命令生成内容的导出兼容。
- 部分结构编辑仍需重建可见列表与行计划，不宣称所有按键路径都与全文规模无关。
- 权限回归覆盖常规文件权限，未验证 ACL 与扩展属性保留。
- macOS 安装包仍未签名和公证；Cargo 提示既有依赖的未来 Rust 兼容性问题，当前构建和测试通过。
