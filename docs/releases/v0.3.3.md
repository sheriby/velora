# Velora v0.3.3

本版是 v0.3.2 全量评审之后的一批缺陷修复。最直接的两条：从网页或文档复制带下划线的名字，粘进来不会再变成 `flash\_attention\_score`；纯文本与代码文件里的复制粘贴按原文落笔，不再把 Markdown 记号塞进剪贴板。其余按评审条目逐条修掉，涉及 Vim 的多块语义、表格竖线切分、链接标签的转义写法、主题缓存、配置写入、双链路径校验、AI 历史清理与打印失败。

## 🐛 修复

**剪贴板与粘贴**

- 从带 HTML 的剪贴板粘标识符（如 `flash_attention_score`）不再被改写成 `flash\_attention\_score`。词内下划线本来就不会成为强调定界符，那颗替它加上的反斜杠从此不进缓冲区，也就不再跟着存盘文件、导出与再次复制跑到别处。`_foo_` 这类可能配成强调的写法仍按原样转义。
- 纯文本与代码文件里的复制给的是文件原文：`\.`、`\_`、`\\` 不再被翻倍，选区末端也不再被截断。
- 纯文本与代码文件里的粘贴不读剪贴板的 HTML 版本，也不把「选中文字 + 网址」改写成链接，落下的就是剪贴板那几个字符。

**编辑与写作**

- 表格格子里有行内代码且代码里带竖线（`| \`a|b\` | c |`）时，格子级编辑落在正确的字节区间，不再把内容写进隔壁格子。
- 链接与图片的标签里用反斜杠转义过的记号，编辑一次后仍逐字节写回，不再被还原成裸记号而改变语义。
- 公式弹窗不改任何字符地按「应用」不再削掉正文的空白，也不再产生一笔没做过的撤销。
- 文档末尾自动补出的段落会置脏并进入撤销组：关闭时提示未保存，撤销能删掉它。
- 代码块里选中文字后键入 `*`、`"`、`(` 等包裹符号，不再把记号注进代码内容。

**Vim 模式**

- 段末按 `x` 或 `dw` 不再把两段并成一段；`gUU`、`g~~`、`gcc` 在非末尾块的最后一行生效。
- `ci"` 这类目标解析失败的命令不再把下一笔编辑并进同一次撤销，`.` 也不再重放没生效的命令。

**主题与渲染**

- 切换主题后，滚回视口的块文本不再按旧主题的颜色绘出；主题指纹改用换代计数，地址复用不再串缓存。
- 上一帧布局与当前文本行数错配的帧，光标移动与命中测试不再 panic。

**工作区与配置**

- 跨行正则（如 `a\nb`、`(?s)`）的「全部替换」与确认框计数，与结果列表是同一份命中：此前列表有结果、计数为 0、替换空手。
- 清空代理设置立即生效，不再等下次重启。
- 后台窗口位置写、偏好设置保存与偏好对话框保存不再互相回滚；恢复快照改走同一条原子写路径，文件建出即收紧权限。
- 双链目标含路径分隔符或 `..` 时拒绝执行，不再在工作区根目录之外新建或打开文件。

**导出与打印**

- 打印失败改为应用内提示，不再崩溃。
- 嵌在语义容器里的 HTML 图片导出时换源：作者的本地绝对路径不再进分享件，图也不再碎。
- LaTeX 公式缓存与 mermaid 同口径：写到一半的缓存文件不再顶掉好档，清理缓存目录后公式区自动重建，不再永久空白且无提示。

**AI 助手**

- 清理历史不再删掉正在使用的会话文件（此前该会话之后的保存会被静默拦住，对话记录丢失）。

**菜单与键位**

- 原生菜单与命令面板的「切换 Vim 模式」生效；焦点不在文档里（窗口刚开、侧栏输入框）时菜单的「关闭标签」也生效。
- Windows 上缩放可用键盘：`Ctrl+=`、`Ctrl++`、`Ctrl+-`、`Ctrl+0`。

## ⚡ 性能

- callout 已有正文时按 Enter 只移动焦点，不再整篇重建引用注册表（10 MiB 文档单键实测 766ms）。

## ⚠️ 语义变化

- 纯文本与代码文件里的默认复制改为原文。v0.3.2 及之前按 Markdown 序列化，会把反斜杠翻倍。
- 代码块内键入包裹符号不再包住选区：按「代码内容不注记号」的口径一律原样插入，与 VS Code 的引号/括号惯例不同。

## ⚠️ 破坏性变更

无。配置文件、会话文件与主题格式向后兼容。

## 🧪 测试与可靠性

- 自动测试由 2941 项增至 2970 项，全部通过；53 条慢用例与诊断探针默认跳过；生产构建零警告。
- 相比 v0.3.2 共 17 笔提交，涉及 54 个文件，新增 1565 行、删除 235 行。
- 新增 `docs/reviews/v0.3.2.md`：19 个模块块的缺陷导向评审，18 必修 / 46 建议 / 15 存疑；每条必修的去向记在报告末尾的「修复记录」。
- 每处修复都带一条能红的用例，其中多条经 stash 隔离确认过旧行为确实失败。

## ⚠️ 已知限制

- 行表错配那一类 panic 属防御补齐：两处评审结论都没能构造出确定可达路径，按「依赖同一次事件批次内先改文本后命中测试」的调度窗口处理。
- 评审建议项里「引用定义扫描器约 250 行整族收编」是纯重构，本版未做，留单独立项。
- 行内 HTML 的 `src` 不在换源范围内，导出时仍按原样保留。
- 主题代数的守卫用例无法对旧实现跑红：地址复用不可确定复现，只能钉住换代计数的推进。

## 📝 其他

- 注释措辞：不再用「味道」称呼剪贴板里的 HTML 版本与纯文本版本。
