# v0.2.4

文件树的新建与重命名改为直接在树中输入，右键即可选中目标，常用路径复制与文件管理器操作齐备。六套主题共用更紧凑的列表排版和清晰的标题层级，H1/H2 居中，正文粗体使用主题强调色。Windows 和两种 macOS 架构的验证与出包均改为原生构建。

## 📦 下载

| 平台 | 文件 | 说明 |
| :--- | :--- | :--- |
| macOS (Apple Silicon) | `velora-0.2.4-macos-arm64.pkg` | 双击安装 |

## ✨ 新增

**文件树操作**

- 新增「新建文件」，可输入任意文件名和后缀；「新建 Markdown 文件」默认 `untitled.md`，先选中文件名部分，后缀仍可修改。
- 新建文件、文件夹和重命名直接在文件树中输入，支持中文输入法、名称选区、Enter 确认、Esc 取消和 F2 重命名。
- 右键菜单新增「在文件管理器中打开」「复制绝对路径」「复制相对路径」「复制文件名」，按操作分组显示。
- 重名在输入行提示；其它文件操作错误使用应用内模态。重命名同步更新打开标签和图片基目录，保留未保存内容。

**阅读与窗口**

- 无序、有序和任务列表共用标记列宽与首行对齐，项间留白收紧；圆点和复选框的外观同步调整。
- H1/H2 居中，H3 保持左对齐；六套内置主题增强标题字号层级并取消标题下划线。正文粗体跟随主题强调色，长标题换行后的光标与选区同步对齐。
- 写作宽度可随窗口按紧凑 50%、标准 62%、宽敞 75% 展开，窄窗口保留对应下限；「跟随主题」保留主题设定。
- 侧栏启动时默认展开；收起后不会再因指针经过窗口左缘而自动弹出。

## 🐛 修复

- 右键文件后，重绘把目标改回活动文档，导致复制、重命名等操作作用到其它文件；菜单现在固定绑定点击时的目标，文件树焦点与正文焦点独立。
- 文件树悬停提示可能盖住右键菜单；弹出菜单和名称输入时抑制提示。
- 二级菜单在指针经过父行与面板之间的缝隙时过早收起。
- 公式草稿光标因闪烁阶段卸载，慢机器上布局边界取不到；光标保持挂载并通过透明度闪烁。
- Windows 自定义快捷键的菜单显示遗漏平台修饰键；规范化后的 `win` 和 `super` 别名现在完整显示。
- Windows 原生链接重复嵌入 manifest 导致无法构建；应用统一提供 manifest 与图标，保留 Common-Controls 和 DPI 设置。

## ⚠️ 语义变化

- macOS 的 `Cmd+W` 与其它平台的 `Ctrl+W` 用于关闭活动标签；macOS 关闭窗口改为 `Cmd+Shift+W`。
- 侧栏开关不再默认绑定 `Ctrl+W`。空选区时 `Cmd/Ctrl+B` 切换侧栏，有选区时仍执行加粗；用户自定义绑定继续生效。
- 旧配置中的「跟随主题」仍保持主题宽度；希望使用比例宽度时可在设置中选择「标准」等档位。

## ⚠️ 破坏性变更

- 文件树的「重命名或移动」改为「重命名」，只接受同目录内的新名称，不再通过路径输入跨目录移动。移动文件请使用系统文件管理器。

## 🧪 测试与可靠性

- 默认测试通过 1610 项、忽略 36 项；CI 另跑确定性慢用例，并排除依赖真实耗时的预算闸门。
- 发布前改动共 21 笔提交，涉及 111 个文件，新增 4195 行、删除 1989 行。
- 新增文件树名称编辑测试，覆盖文件后缀、中文输入、取消、重名保护、目录重命名、未保存内容、路径复制及真实右键操作。
- macOS ARM64、macOS Intel、Windows x64 分别在原生 runner 上构建与运行测试，Windows 使用 MSVC。
- 文件树首次扫描限制为三层，更深目录在展开时读取；搜索与快速打开的文件名单在后台独立维护。

## ⚠️ 已知限制

- macOS 安装包仍未签名和公证。安装、字体观感和不同设备上的交互仍需实机验收。
- Cargo 提示既有依赖的未来兼容性问题，当前构建与测试可用。

## 📝 其他

- Windows 出包统一使用正常 release 配置，关闭调试断言并在构建时预编译着色器；公开安装包保留默认 CPU 兼容性。
- 发布工作流提供仅构建并上传安装包的手动验证入口，支持分支验证；更新发布说明保留独立操作。
- 开发工具链说明统一使用 Rust stable，中英文文案、主题变量及架构文档同步更新。
