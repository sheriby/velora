# v0.2.7

本版集中落地 v0.2.6 代码评审提出的修复批次：覆盖 Markdown 往返保真、保存与数据保护、导出与分享安全、编辑交互四族问题，并完成一轮性能收敛——滚动、光标闪烁与表格高亮等热路径不再按可见块数重复付出开销。侧栏、面板、文件树与启动行为的细节一并修正；项目文档整备为架构、发布、评审三块，双语 README 同步到最新功能。

## ✨ 新增

本版专注修复与性能，无新增功能。

## ⚡ 性能

- 文本未变的帧不再重建排版产物，滚动与光标闪烁期间的开销不再按可见块数放大。
- 表格高亮只写真变化的实体：一次预览加一次选列的写入从 20 次降到 8 次。
- 未闭合块级公式并段的定位改为增量：22 段语料的重建从 25 次降到 3 次。
- 复制为 HTML 改为后台执行，动作立即返回，长文档不再冻结窗口。
- 窗口菜单树按安装代数缓存、设置安装收敛为单次配置读取、文件树排序键按节点缓存，这些路径不再每帧或每次扫描做深拷贝与重复系统调用。
- 缩进代码块的源码映射由平方级降为线性；多行围栏与 front matter 的高亮合并区间并复用解析器，解析入口由 3 次降为 1 次。
- 稳定帧的块渲染不再各自克隆整份主题；界面缩放后滚动条进度与占位高度即刻正确。

## 🐛 修复

**编辑与交互**

- 多行块（代码块、引用、源码块）内 Home/End 按光标所在行落点，不再跳到整块两端。
- 输入法拼音组合中移动光标或点击别处后，后续输入不再写回旧位置。
- 选中文字粘贴网址：全大写的 `HTTPS://` 也能生成链接；选区端点落在多字节字符中间不再崩溃。
- 全大写的 `FILE:` 图片地址正常加载；链接悬停的「存在性」结论与点击一致，mailto 与纯锚点不再被误判为不存在。
- `c++` 围栏别名正常高亮；文件历史浮层的版本日期恢复正确。
- 命令面板选中项首尾环绕；`⌘P` / `⇧⌘P` 面板改为居中浮层，不再顶替正文。
- `⌘/Ctrl-B` 在窗口内任意焦点状态下都能开合侧栏；收起侧栏时焦点交还正文。
- 窗口不在前台时不再为光标闪烁持续重绘。
- 重命名正在编辑的文档后自动保存恢复正常；未保存的新文档，其相对链接与图片按工作区根解析。
- 直接打开文件启动的窗口也应用侧栏启动设置与全局记忆；偏好设置里侧栏两项保存后不再残留「未保存」标记。
- 主题、语言应用失败时回退界面并报告错误；窗口尺寸保存不再被悄悄收紧。
- 插入表格的对话框与建表入口设规模上限（100 行 × 30 列），不再能一步建出数万块。
- 缩进代码块转正文再转代码块时不再丢失围栏；表格格映射先与写回形态对账，不等长的格子不再产生错位落点。

**Markdown 与公式**

- 行内语法判定统一：代码跨度不误处理转义；强调、删除线与高亮采用一致的标点侧翼规则，`2~~(3+4)~~5` 与 GFM 一样不再整段划线；含空格与括号的链接目标正确重建。
- setext 标题判定、标题锚点与 Markdown 文档扩展名的判据统一，列表遇到同级分隔线正确终止。
- 任务项 `[X]` 大写勾选框写法往返逐字节保留。
- 标题分隔符接受制表符与全角空格：`##\t标题`、`##　标题` 在阅读视图、大纲与导出中一致。
- 块级公式闭合符认反斜杠转义（`$$a\$$` 正常闭合）；段中的块级公式在导出中不再被压成行内尺寸。
- 引用内 1–3 空格缩进的围栏正确触发重解析；搜索模糊命中的重叠区间被过滤，替换与高亮恢复从后往前的正确前提。

**保存与数据保护**

- 后台替换、保存失败与换根路径收紧：保存失败会中止关闭或换根，换根提供保存 / 丢弃 / 取消；全文替换继承目标文件形状；历史读取经过解码漏斗。
- 无法解析的配置不再被覆盖，启动只在缺失或迁移时回写，`config.toml` 的注释得以保留。
- 原子写入穿透符号链接保存到真实目标，iCloud 等同步盘工作流不再被换成普通文件。
- 配置目录内的文件（恢复快照、会话、历史版本）收紧为仅本人可读。

**导出与分享安全**

- 导出统一 URL 白名单并添加 CSP：危险协议的链接与图片被移除；本地图片内联限定在文档目录内、单张读取上限 50 MiB；目录外的绝对路径图片以中性占位呈现，不再泄露发送者路径。
- 远程图片请求增加连接与响应超时、累计响应上限与有界并发；网络能力缺失时占位框给出真实原因。
- 公式 SVG 缓存增加容量上限与格式版本键；mermaid 缓存键按亚像素分档、读写原子化，拖动窗口不再使缓存目录无限膨胀。

## ⚠️ 语义变化

- 多行块内 Home/End 变为行级导航，与主流编辑器一致。
- `~~` / `==` 采用标点侧翼规则后，部分此前会被划线的写法将与 GFM 一样不再成对。
- 侧栏：`⌘/Ctrl-B` 在任意焦点下可用；收起侧栏会把焦点带回正文。
- 配置仅在缺失或迁移时回写；解析失败保留原文件。
- 符号链接的保存动作穿透到真实目标。
- 导出的分享物不再保留危险协议与目录外绝对路径；本地图片内联限于文档目录、单张上限 50 MiB。
- 插入表格上限为 100 行 × 30 列。

## ⚠️ 破坏性变更

- 无。既有文档、配置与会话无需迁移。

- 本地默认测试从 1801 项增至 1918 项通过（+117），0 项失败、36 项忽略；确定性慢用例 20 项全部通过。构建通过，无源码编译警告。
- 发布准备前共 73 笔提交，相对 v0.2.6 涉及 197 个文件，新增 6683 行、删除 4150 行。
- 评审批次的修复多数先以失败测试复现再修，并新增形状探针守住每帧重复成本（每帧构建次数、实体写入次数、重建次数）。
- 本地验证运行于 macOS；macOS ARM64、macOS Intel、Windows x64 的构建、默认测试与确定性慢用例由原生 CI 执行。

## ⚠️ 已知限制

- 符号链接穿透保存与窗内菜单树缓存的两处 Windows 侧形状本机无法构造真红，待 Windows runner 验证。
- 旧版 mermaid 缓存文件在换键后不再被读取，但目录暂不自动清理。
- macOS 安装包仍未签名和公证，在线安装需要系统授权。
- Cargo 提示既有依赖的未来兼容性问题，当前构建与测试通过。
