# Velora

支持边打字边渲染：行内样式有**粗体**、*斜体*、~~删除线~~、`行内代码`、==高亮==，[链接可指外部地址](https://github.com/sheriby/velora)，也可跳[文内锚点](#1)。

| 快捷键 | 动作 |
| --- | --- |
| `⌘B` / `⌘I` | 粗体 / 斜体 |
| `⌘F` | 查找与替换 |
| `^Tab` | 切换源码模式 |

质能方程 $E=mc^2$ 直接排在正文里，块级公式也一样：

$$
\int_{-\infty}^{+\infty} e^{-x^2}\,dx = \sqrt{\pi}
$$

- 回车续写列表，`Tab` 缩进、`⇧Tab` 升回
  - 支持任意层嵌套，记号族不会被改写
- [x] 导入、编辑、导出逐字节对齐
- [ ] 剩下的评审必修项

代码块带语法高亮，右上角一键复制：

```rust
fn word_count(blocks: &[Block]) -> usize {
    blocks.iter().filter(|b| b.is_text())
        .map(|b| b.text().split_whitespace().count()).sum()
}
```

> 引用块里的样式同样生效，脚注挂在这里[^1]；`[[引用笔记.md]]` 点击即打开或创建同名笔记。

[^1]: 脚注与链接引用支持悬停预览，`[TOC]` 渲染成可点击目录。
